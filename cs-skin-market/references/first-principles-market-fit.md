## 1. 执行摘要

系统「在售量 + 价格」双核心的建模与 CS 饰品市场的真实机制**大体吻合，但有明确边界**：

- **吻合面**：饰品是低效、情绪驱动、可被资金控盘的挂单市场，均值回归与供给收缩逻辑在 365d 回放中表现为正期望（2026-08-10 落地 v2-T4 后：**317 信号，win14 71.0% / avg14 +15.95 net2%**，`data/item_backtest_full_2025.json`）；供给吸筹族贡献最大（+111.69pp，`data/portfolio_attribution.json`），恐慌族 +56.35pp——说明「在售量收缩 + 价格企稳」在样本内确与后续上涨相关。
- **边界面**：① 在售量是单平台挂单存量，非可成交深度，且可被假挂单/撤单操纵；② 锚价（悠悠 `yyyp_sell_price`）是卖盘报价而非成交价，2% 双边成本假设未实盘校准（A1-4，executions 仅 7 条）；③ **回放情绪为价格近似，与生产贪婪指数不同源**（T1 探针：60 天窗口日级 corr 0.26/MAD 19.5，但决策级影响为零），恐慌族 92 信号的外推需生产样本验证（C 通道累积中）；④ 执行环未闭环，选股/择时 alpha 未经真实成交验证——已知结论「引擎边际价值在风控」仍然成立。

**一句话结论**：系统作为「防守型风控引擎」符合 CS 饰品市场的特征（回撤 13% vs 池 55%/大盘 58%）；作为「选股/择时引擎」存在未验证的 alpha 候选（趋势腿 S2/S3）与若干系统性遗漏（开箱供给节奏、事件日历、求购、跨平台价差），属于「机制匹配但证据链未闭合」。

**测试执行与落地（2026-08-10）**：首轮只读（成本阶梯证实 2% 假设对整体稳健，盈亏平衡 17.4%；「高价≥1000 × 低在售<200」win 53.7% vs 低价 80.6%；「供给收缩 + 8 日动量>3%」子集 win 42.3%）→ **P-1 正式引擎 A/B 通过并落地**：吸筹族新增 chg8（8 日动量）>3% 禁买门，基线 332 → 变体 317 信号（−26 剔除 +11 去重链解锁），win14 69.9→71.0%、wavg14 20.47→21.04、wwin14 74.4→75.4%、事件 14→15、win30 不劣化——全指标改善无劣化（真实引擎增益 +1.0pp 小于只读模拟 +1.9pp，去重链动态所致）。P-2（高价×低在售联合闸门）维持候选，待扩池样本 + 消融 + 三件套。T0 greedy 持久化机制验证通过（60 天覆盖）；T1 首轮探针已出（日级不一致、决策级零影响）。

## 2. 三个总问题的直接回答

### ① 核心量价假设（在售量=供给、锚价=可成交价）在什么条件下成立/失效

| 假设 | 成立条件 | 失效条件 |
|---|---|---|
| 在售量 ≈ 供给（短周期） | 单平台挂单行为真实、无系统性撤单操纵；开箱热度稳定；跨平台分流可忽略 | 庄家假挂单/撤单；新箱上市或热度切换（供给主变量=开箱产出，不在在售量内）；B-3 记录的 30-80% 平台 SALE 偏差放大 |
| 锚价 ≈ 可成交价 | 挂单厚度足够（系统已内置 supply_depth≥15 闸门）；报价为真实卖价 | 低流动性品（15-50 在售的高价品真实可成交深度可能 <1 件）；虚挂/异常报价（已有 20% 锚校验兜底，`analysis_service.py:211-251`） |
| 2% 双边成本 | 中高流动性品挂单买卖 | 低流动品吃单冲击 >2%；或求购价成交（成本 <2%，吃 bid）——实际成本取决于执行方式，未建模 |

**结论**：双核心假设在「在售量≥15 + 价格锚校验通过 + 中高流动性」子集内大体成立；最大未验证项是 2% 成本与真实滑点（A1-4）。

### ② 除风控外，是否存在可验证的选股/择时 alpha 空间

- 现有证据：族级归因显示供给吸筹 +34.2pp / 恐慌 +21.65pp / 深值 +13.98pp（`portfolio_attribution.json`），但策略整体低于池内等权（+83.65% vs +252.31%），差额主因 2025 低价品暴涨集中度（top10 占 43.5%）——**信号有正贡献，但被集中度结构压制**。
- 候选空间：`references/trend_leg_research.md` 的 S2 回踩（W2 30d +22.5%）与 S3 吸筹（W2 30d +31.4%，全窗口近全桶为正）是「非恐慌上涨段」的可验证 alpha 通道，路由层草案 v0 已设计、未落地（需 A2 三件套 + 路由门控验证后并入）。
- 结论：**存在可验证的 alpha 候选（趋势腿），但当前引擎的已验证价值仍是风控**；alpha 落地须走 C1/趋势腿立项流程，本报告不预判结果。另：首轮测试给出「负 alpha 剔除」候选（吸筹族 chg7 门，模拟三件套通过），属低成本改进路径。

### ③ 哪些 CS 市场核心机制被系统性遗漏

1. **开箱供给节奏**（I-12 观察项）：开箱是新增供给主渠道，新箱上市→开箱量→供给扩张→衰减的价格生命周期未被捕捉（在售量只能看到后半段）。
2. **事件日历空白**：`EVENT_CALENDAR`（`pipeline/config.py`）仅 3 条历史黑天鹅，未来条目为 0（F-1 提示框架已就绪，等用户按赛程配置）。
3. **求购单数据**：`order_book` 已采集（`collector_csqaq.py:607-660`）、快照 5 列已落库，但 bid_count 为估算、bid_30d_chg 不可信、因子未验证（F-2，90+ 天样本）。
4. **跨平台价差**：B-3 记录的 30-80% SALE 偏差是平台流动差异，也是信息（跨平台套利/流动性迁移），未利用。
5. **真实成交与冲击**：执行环（executions 7 条）与信号跟踪（1 条）未闭合，滑点/手续费/可成交性无实证。

## 3. 八域分析矩阵

### 域 1 · 价格发现

**系统当前假设**
- 定价锚优先级：悠悠有品（platform=2）> Buff > C5GAME，Steam 仅参考；权威锚 = `info/good.yyyp_sell_price`（API 优先，DOM 兜底）（`pipeline/collector_csqaq.py:485-586`）。
- 单品价格序列 = chart API 90 日 close（每日聚合末点），chart 与悠悠锚 >20% 判脏/校正（`webapp/analysis_service.py:211-289`；`collector_csqaq.py:748` fetch_kline_90d 锚校验）。
- 求购价/spread 已采集为辅助（`item_analysis.py:863` compute_bid_support；守卫 `item_analysis.py:1135` `_g_bid`）。

**真实机制**
- 悠悠/Buff/C5 是 C2C 挂单平台：锚价本质是「卖方最低报价」（或平台参考价），**不是成交价**；低流动性品单笔挂单即可主导报价。
- 求购价（order_book）是更接近「可成交价下界」的买方意愿，系统已采集但未进决策（F-2 等样本）。
- 跨平台价差客观存在（费率/提现/用户群差异），锚价只代表一个平台。

**差异与风险**
- P1：回测 entry = chart close，与「实际可成交价」之间滑点未知（A1-4 待 executions≥20）；2% 假设未校准。
- P2：锚价（最低卖价）与求购价（买价）断层 `spread_pct` 未被回测使用——真实成本取决于执行方式（挂单买=吃卖单，约等于锚价；求购买=吃买单，低于锚价）。

**可证伪检验（待执行）**
- 只读：统计 `snapshots.bid_highest / spread_pct` 分布（T1 已验证 8/8 品非空，bid_30d_chg 禁用）；若 spread_pct 中位显著 >2%，则 2% 双边成本对「挂单买入」偏乐观，支持 F-4 成本建模。
- 实盘：executions.advice_price vs exec_price 滑点 ≥20 条（A1-4 已在等）。

**建议**：保持锚优先级；F-2 样本满 90 天后按 `bid-data-accumulation.md` 验证计划推进；F-4 成本建模（P1 研究层）优先纳入 spread 分布。

### 域 2 · 流动性

**系统当前假设**
- 在售量 = chart `num_data` 当日末点（`collector_csqaq.py:78-132`），作为可交易深度代理；B-3 已验末点口径偶发偏差（5 品 0-1 天敏感日），非系统性。
- 流动性分 = 在售深度 50% + 价格稳定 50%（`item_analysis.py:447` score_liquidity）。
- buy 闸门：综合分 <30 或 0<在售量<15 → 降级 watch（`pipeline/trend_health.py:671` compute_fusion_decision 尾部 liquidity filter，F-3.5）。

**真实机制**
- 饰品流动性按价格带/品类差异极大：印花/箱/胶囊在售千级，高价刀/手套在售个位~几十；「在售量」= 单平台挂单**存量**，非成交速率——去量后无成交维度，**无法区分「流动性好」与「无人问津」**（在售 500 也可能一天 0 成交）。
- 挂单可撤 → 在售量可被庄家瞬时放大/缩小（假挂单）。
- 低流动品（在售 <15）已有闸门保护，但 15-50 的高价品真实可成交深度可能仍 <1 件。

**差异与风险**
- P1：在售量 ≠ 可成交深度；「僵尸流动性」（高在售低成交）未被区分。
- P2：只有 in_sale_count 标量，无挂单厚度分布/价差动态。

**可证伪检验（待执行）**
- 只读回放分桶：212 条 supply_accum 信号按最新在售量（15-50 / 50-200 / 200-500 / 500+）对比 net14/win14——若 15-50 桶显著更差，说明在售量下限或展示警示需重议（改参数须三件套）。
- 实盘：低在售品成交滑点（executions 积累）。

**建议**：保持闸门；新增观察项「僵尸流动性」标记（先展示层，不回引擎）。

### 域 3 · 供需结构

**系统当前假设**
- 供给趋势 = 在售量 7/30/90 日变化率；吸筹 = 收缩+价格稳/涨，派发 = 扩张+价格平/跌（`pipeline/supply.py:29-124`）。
- 供给×价格维度进趋势健康（`trend_health.py:366` `_dim_supply_price`）；在售量 30 日扩张 >5% 禁买（`item_analysis.py:1182` `_g_supply_expansion`）。
- 供给收缩吸筹族 = 最大信号源（212 信号 / +34.2pp）。

**真实机制**
- 饰品真实供给 = **开箱新增**（新箱/在产箱持续产出）+ 存量回流（玩家出货）+ 跨平台流转；在售量只捕捉「当前挂单存量」一个环节。
- 「在售量下降」的替代解释：① 真吸筹（大户扫货）② 挂单撤走观望（流动性收缩）③ 下跌惜售（无人挂卖）——三种情形未来价格含义不同，系统统一按「吸筹」打分。
- 新箱生命周期：上市初期开箱量大 → 供给高速扩张 → 热度衰减 → 供给收敛、价格分化；系统无开箱率输入（I-12 暂缓），90 天窗口只能看到后半段。
- 事件性供给（Major 纪念品/新箱/收藏品复刻）由 `EVENT_CALENDAR` + 炼金/纪念品折扣（`supply.py:100-123`）部分覆盖。

**差异与风险**
- P1：吸筹检测的**机制解释可能错**（更可能「低供给→价格刚性」而非「庄家吸筹」），但回测为正——信号有效、机理需修正。
- P2：供给趋势对「开箱新增」不可见，新箱上市/热度切换时信号滞后。

**可证伪检验（待执行）**
- 只读回放拆桶：supply_accum 按「收缩 + 价格 7 日 <0% / 0-3% / >3%」拆，对比 14d——若「收缩+微跌」桶仍正期望，则更接近「供给刚性」而非「吸筹」机制；若显著为负，现有 `_dim_supply_price` 已隐含过滤，无需改。
- 周度：`monitor_rank_snapshot`（大户集中度）× 供给收缩交叉（大户增持+收缩 = 真吸筹；样本积累中）。

**建议**：保持；将替代解释写入 F-2 求购验证的对照假设；I-12 开箱因子保持低优先级观察项。

### 域 4 · 情绪与周期

**系统当前假设**
- 情绪 = 贪婪指数逆向映射（`pipeline/market_macro.py:127-163`：raw≥150 → sent 5 极端贪婪危险；raw<60 → sent 95 极度恐惧机会）。
- 六态状态桶（`pipeline/market_context.py:162-192`）；恐慌阈值 sent≥75；守卫1 market_weak（大盘 TH<45 且 mchg30<0 禁买）已冻结。
- 事件日历 `EVENT_CALENDAR`：3 条历史黑天鹅 + 未来条目由用户配置（F-1 提示层已落地）。

**真实机制**
- 贪婪指数是市场派生指标（由涨跌/成交/玩家行为合成）→ **情绪本质是价格的滞后函数**，与价格因子存在内生共线性（概率去 z 已消除与位置的双计权，但情绪仍是大盘派生）。
- 逆向情绪（散户追高→反向）符合行为金融假设；CS 饰品散户化程度高，追涨杀跌显著（2026-05 恐慌簇、W1/W2 研究支持）。
- 大赛/Major/大促是需求外生脉冲：EVENT_CALENDAR 未来条目为 0，事件驱动提示层 F-1 目前无数据可提示。

**差异与风险**
- P1（关键）：**回放情绪口径 ≠ 生产情绪口径**——回放 sentiment 来自价格近似 `approx_sentiment`（`pipeline/backtest_common.py:12-19`）或真实贪婪指数（仅 2026-06-03 起有），365d 回放 332 信号中 panic 族 93 信号的胜率建立在近似情绪上；生产 panic 信号由真实贪婪指数驱动 → **外推需生产样本验证**（C 通道，当前 1 条）。此为观察项，不推翻 panic 定论。
- P2：事件日历覆盖不足；情绪与价格内生，单独解读需谨慎。

**可证伪检验（待执行）**
- C 通道生产样本 ≥20 条后，对比「回放近似情绪触发」vs「生产真实贪婪触发」的 panic 族胜率（J-2 流程已有，无需新脚本）。
- 只读：macro_history 贪婪指数 vs market_index 的 30 日相关（评估内生程度）。

**建议**：保持（TH/情绪结论冻结）；将「回放-生产情绪口径差异」登记为观察项，C 通道达标前不调 panic 参数。

### 域 5 · 庄家与操纵

**系统当前假设**
- 庄盘四因子：供给骤增 40%（替代成交量）/ 低波锁仓 25% / 价格横盘 20% / 相关性 15%（`item_analysis.py:662` analyze_whale）。
- 分类规则：低位吸筹锁仓 / 高位供给涌出 / 供给收缩拉升（whale_type）；whale_prob 软折扣进 TH（>60 → ×0.70，`trend_health.py:530` 附近 multipliers）。

**真实机制**
- 饰品庄家 = 大资金囤货商，手法：① 假挂单压价/托价（影响 in_sale_count 与 chart close）② 低位扫货（在售量骤降）③ 拉高对倒制造热度（去量后无成交量维度，此手法不可见）④ 高位分批派发（在售量温和扩张）。
- 「供给骤增=派发嫌疑」方向正确（高位派发伴随在售上升）；但「在售量骤降=吸筹」只进 whale_type 标注，**不参与守卫/仓位**——而它恰与供给收缩族（最大 alpha 源）重叠。
- 检测基于被操纵的同一数据源（在售量/价格）→ 内生性：假挂单可同时骗过供给维与位置维。

**差异与风险**
- P2：庄家检测有内生性，仅作展示与软折扣、不硬拦截——设计正确（硬拦截会误伤，I-2 先例），但「低位吸筹锁仓」类机会未被利用。
- 大户集中度（`monitor_rank_snapshot` 每周）是独立于价格的供给侧证据，尚未与信号交叉。

**可证伪检验（待执行）**
- 只读：`monitor_rank_snapshot` 大户增持/减持 × supply_accum/panic 信号交叉表（样本少，先积累）。
- 回放拆桶：whale_prob≥35 vs <35 的信号 14d 对比（验证软折扣是否真降期望）。

**建议**：保持；新增观察项：大户集中度 × 供给收缩交叉验证。

### 域 6 · 交易摩擦

**系统当前假设**
- 2% 双边成本：回放 `cost=0.02`（`references/run_item_backtest_full.py:52`）；生产信号回填 `COST_PCT=2.0`（`pipeline/signal_tracking.py:14`）。
- 无平台费率/提现/价差建模；executions.advice_price（建议价）用于滑点校准（A1-4）。

**真实机制**
- 平台摩擦 = 卖家手续费 + 提现费 + 买卖价差 + 冲击成本；低流动品吃单冲击可能远超 2%（挂单稀疏，吃单推价）。

- 注：悠悠/Buff 现行费率未核实（**待用户按平台规则确认**，本报告不编造数字）。

**差异与风险**

**可证伪检验（待执行）**
