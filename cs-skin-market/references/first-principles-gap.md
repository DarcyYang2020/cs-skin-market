# 第一性原理差距分析（2026-08-08）

> 触发：用户问「从第一性原理出发，该项目离真正好用的量化工具还差什么」，确认「可以」后落档。
> 定位：战略层文档——不回答「下一步做什么」，回答「这个工具最终要成为什么、当前卡在哪一环」。
> 配套：落地计划见 `iteration-roadmap.md` v42（P0-P2 三批），决策见 `decision-log.md` 同日期章节。

## 一句话现状

系统是**防守型纸面量化工具**：数据与决策环完整（每日 18:00 采集 / 单品+大盘分析 / 融合决策 / 买点接近度），
但「建议 → 真实成交 → 回报」的执行环**有表有 API 却从未被日常使用**（库内仅 1 条手动录入），数据飞轮没有真正转起来。

## 量化工具的第一性价值链

一个「真正好用」的量化投资工具 = 四环闭环，缺一环则整条链的价值衰减：

1. **数据**：覆盖（全市场 vs 自选）+ 深度（历史长度 / 在售量 / 求购）——决定「能不能看见机会」。
2. **决策**：信号 → 可执行动作（买 / 卖 / 仓位 / 位置）——决定「看见后能不能行动」。
3. **执行**：真实成交记录 + 真实成本（价差 / 手续费 / 冲击）——决定「行动后赚不赚」。
4. **反馈**：回报回填 → 引擎迭代（胜率 / 滑点 / 成本归因）——决定「能不能越用越好」。

当前：1、2 完整度较高；3 有数据表与 API（P0-2 执行记录，2026-08-04 建表）但仅 1 条手动记录；
4 只有「纸面回填」（signal_tracking 按价格回填 14/30 日），没有「真实执行 vs 纸面信号」的对照，也没有滑点 / 成本归因。

## 实证：引擎的边际价值在风控，不在收益增强

`data/benchmark_compare.json`（370 信号，2025-01-01 ~ 2026-08-05，扣 2% 双边成本）：

| 口径 | 总收益 | 最大回撤 | 年化 |
|---|---|---|---|
| 策略（cap0.8 / hold14） | +193.30% | -9.39% | +110.1% |
| 同策略无 cap（参考） | +1118.94% | -44.68% | +461.5% |
| 池内 95 品等权买入持有 | +509.75% | -54.12% | +211.4% |
| 大盘指数 | -4.02% | -58.21% | -2.5% |

结论：
- 引擎相对大盘大幅超额（+193% vs -4%），但绝对收益低于池内等权买入持有（+509.75%）；
- **引擎的真实边际价值 = 风险控制**（maxDD -9.4% vs 池 -54% / 指数 -58%），即「用 -9% 的回撤拿到 193% 的收益」；
- 收益增强 alpha（选股 / 择时能否跑赢池内等权）**未被验证**——这是「纸面好看」与「真实可信」之间的根本差别。

## 结构性断点（按第一性排序）

1. **执行环摩擦**（最关键）：报告页没有「按建议执行」入口，用户需去自选页手动录入名称 / 价格 / 日期；库内仅 1 条执行记录。
   表、API、自动结算（14/30 日按收盘价回填）都已就位，缺的是「零摩擦录入 + 收益可见」。
2. **反馈闭环未闭合**：executions 已自动回填 settle / pnl，但没有聚合展示——真实累计收益、真实 vs 纸面胜率对照、
   滑点分布（advice_price 列已存但无统计）全部不可见；「按建议操作到底赚不赚」无法回答。
3. **成本模型粗**：回测统一扣 2% 双边成本，无价差 / 流动性冲击建模——在售量小的品真实滑点更大，+193% 是理想化净值；
   `cost_sensitivity.py` 已有雏形未接入官方基准生成链。
4. **覆盖不足**：数据健康检查单品 K 线 + 在售量覆盖 26/104 品，发现机会依赖人工选品；discover 全量重扫受 csQAQ 限流
   （约 25-40 分钟）但可做。
5. **组合层缺失**：cap0.8 只是并发上限，无资金分配（风险平价 / 凯利近似）、相关性、再平衡；这是把「单票信号」
   变成「可执行资金曲线」的最后一公里。
6. **数据积累未到**：260 天 OOS 窗口（约 2027-04-25）未到，冻结期内的任何引擎调参都不具统计功效——当前一切
   「引擎优化」只能发生在展示 / 调度 / 采集 / 数据层。
7. **事件驱动缺失**：Major / 开箱 / 新箱等外生事件（I-12 已暂缓）未接入提示层，机会识别仍是被动的。

## 优先级方案（P0-P2，全不触碰冻结参数）

### P0「把飞轮转起来」（数据层 + 展示层，可立即开工）
- **F-1 一键执行录入**：单品报告 / 自选列表加「按建议记录执行」按钮——自动带名称、建议日期、建议信号、参考价
  （复用 `/api/watchlist/executions/ref-price`），一次点击即记录 + 同步持仓；把「手动 3 步录入」降为「1 次点击」。
- **F-2 执行复盘对照卡**：组合仪表盘加「执行记录复盘」区——执行笔数 / 已结算笔数 / 真实累计 pnl（扣 2%）/
  平均滑点（advice_price→exec_price）/ 14-30 日胜率，与 signal_tracking 纸面口径并列对照；回答「按建议做到底赚不赚」。
- **F-3 全市场扩池**：discover 全量重扫（限流下约 25-40 分钟，可随时点「🔄 刷新」），把 104 品自选池推向全市场；
  数据覆盖是 260 天 OOS 复验的底座。

### P1「让收益数字可信」（研究层，不触引擎）
- **F-4 成本建模进回测**：官方基准生成链（item_backtest_full_2025.json）扣费从「统一 2%」升级为
  「价差 + 手续费 + 流动性冲击（in_sale_count 越小冲击越大）」；cost_sensitivity.py 扩展为成本函数库。
- **F-5 组合模拟器**：资金分配（风险平价 / 凯利近似）、相关性矩阵、再平衡；cap0.8 从「并发上限」升级为真正的组合层
  （研究结论先记候选，冻结期结束后再决定是否进引擎）。

### P2「体验与前瞻」
- **F-6 事件驱动提示**：Major / 开箱 / 新箱事件日历接入提示（非决策，与 I-12 观察项对齐）。
- **F-7 钉钉卡片一键执行 / 移动端**：推送已打通（12:00 + 21:30），可升级为「可确认的卡片式动作」；
  涉及真实资金安全，需二次确认 + 幂等设计，谨慎推进。

## 衡量标准（怎么算「真正好用」）

1. 执行环被日常使用：连续 30 天有新增执行记录，14/30 日结算率 ≥ 90%（有价格即可结算）；
2. 真实执行净值曲线（扣成本）在 260 天 OOS 窗口内与「纸面信号 + 同口径成本」对照不显著劣化（≤ 3pp 胜率差）；
3. 滑点中位数 < 1.5%（否则 F-4 成本建模必须先于任何扩仓建议）；
4. 全市场覆盖 ≥ 500 品（数据积累进度卡可见）。

## 与既有资产的关系

- J-2 三通道 / 260 天冻结：F-1~F-7 全部在冻结纪律内（仅数据 / 展示 / 调度 / 采集层改动）。
