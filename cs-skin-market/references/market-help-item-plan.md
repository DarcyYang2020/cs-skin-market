# 大盘 → 单品 全面帮助方案 v2（主路径第 (2) 步，2026-08-17，待批）

> 用户裁定：(2) 是完整方案 = 先全局盘点单品分析的局限性 → 大盘如何帮助（可设想）→ 探针研究证实/证伪；收藏品分权重与 B 通道 2027-04 重验不进议程。
> **v2 追加裁定（第一性原则）**：单品分析要有自己的独特性，不只是套一层大盘引擎的壳——大盘只帮助其提升。独特性体现在：单品可以给出与大盘相反的信号（大盘要求减仓，单品要求抽象派/合纵持有）；实例=2026-06-20~07-11 大盘走弱（S4 反抽段），FN57 | 霸意大名、格洛克 18 型 | 异星世界等逆市走强。
> 本文只出方案；探针一个都不跑，批准后按第四节顺序执行。

## 〇、原则 0：单品独特性（大盘帮助的边界）

- **独特性 = 大盘捕捉不到的地方，由单品分析去发声**（用户裁定）。两个层次：
  1. **维度分工**：大盘能可靠捕捉的维度（时期/风险档/广度/急跌/共振环境）由大盘帮助提供；大盘**捕捉不到的维度**（单品供给结构、庄盘行为、相对强度、逆市强势、长持结构）由单品自己的因子发声——这些维度不被任何大盘结论覆盖或否决。
  2. **逆市发声权**：单品可以给出与大盘相反的信号（大盘要求减仓，单品要求抽象派/合纵持有）——冲突裁决语义必须显式存在，而不是让大盘闸门静默吞掉单品结论。
- **大盘是环境输入，不是裁判**：任何大盘层结论不得单方面否决单品结论。
- **帮助≠替代**：大盘帮助 = 让单品判断更准（什么环境下这个指纹更可信），不是"大盘说空仓就全部空仓"。(2) 的全部假设都必须通过**独特性护栏**（见第四节）。
- **已有证据链**：S3 里 base 腿 77.8%/+27.4（大盘全负期引擎唯一在赚钱的腿）、S4 里 rise 腿 30d +31.1 肥尾——独特性在现有引擎里只是"幸存"，不是"被设计"；抽象派 1337 +1266%、合纵 +1088% 的长持结构被架构性错过，说明独特性没有正式发声通道。
- **独特性形式是开放集合**（用户裁定：不止"反向信号、逆市走强"两种，需数据挖掘扩表）：已点名的两种作为种子，其余形式由 P13 独特性全景挖掘发现——挖掘产出的每一种形式都必须有定义、样本量与 alpha 证据，才进入假设层。

## 一、单品分析引擎局限性全景（十四项，按层分组）

**A. 信息视野层（只看自己，不看市场结构）**
1. **大盘输入只用 5 个数**：单品引擎拿到的市场上下文只有 chg30/chg180/drop21/TH/cycle——时期已经算好了但广度（breadth5）、波动（vol20）、距高低点、大盘信号（抄底/空仓）都没进单品决策。S1 负增量就是嫌疑现场：引擎不知道"此刻是广度 56% 的慢牛"。
2. **无相对强度视角**：单品 vs 大盘同期超额动量没有因子。抽象派 1337 / 合纵类长持结构的错过（+1266%/+1088%）与"相对强度"视角缺失直接相关——rise_contract 候选被冻也是因为缺少一个能确认"这是独立强势品而非随波"的确认信号。
3. **无截面共振信息**：单品的买点判断不看"同期大盘信号面"。P 期全员超跌时的深跌（V 型底，等权池 14d 86.7%/+15.9 已证）与"大盘平稳时单品独跌"（接刀，deep_value 在 S3 0%/−5.67 已证）在引擎里长得一模一样。

**B. 决策层（族定义静态、与时期错配；独特性无发声通道）**
4. **族定义是静态的**：supply_accum 的 s7≤0.85×s30、|chg7|≤3 等阈值在 S1/S2/S3/S4 共用一套。S1 是引擎唯一跑输等权的时期（+3.6 vs +5.8，−2.2pp）——精选反而输给无脑买，最合理的解释就是族定义与时期错配。
5. **部分参数是旧口径拟合**：deep_value 的 mchg30≤−3 闸门（I-13）是 365d 96 池口径，HQ 3 年 180 池未重验。
6. **路由禁发是修症状不是改定义**：rise_accum 在 S1 被禁（31%/+0.65），但"为什么 S1 追涨失败"没有回答——慢牛里 supply_change_30d>5% 可能不是吸筹而是派发，族定义本身可疑。
7. **base 基础族是黑箱**：S3 里 base 77.8%/+27.4 是全场最强的"隐性精选腿"，但没人拆过它由哪些子条件构成——拆出来就能显式化为 S3 专用族。
14. **逆市发声权缺失（原则 0 的核心缺口）**：守卫1 大盘走弱（TH<45 且 chg30<0）一刀切禁买、时期路由按大盘禁发、deep_value 要求大盘企稳——三道大盘闸门之外，引擎**没有任何"独立强势品"的买入/持有通道**（rise_contract 长持候选被冻、默认关）。2026-06-20~07-11 大盘 S4 走弱期间霸意大名/异星世界逆市走强，引擎既不能买也不能明确说"持有"——独特性只在市场走弱时恰好存活的 base/rise 腿上偶然体现，没有被设计。

**C. 仓位层**
8. **单品仓位无时期风险折让**：族级固定 limit（0.3/0.2/0.15/0.05…）+情绪修正，不含时期/风险档。注：组合层时期乘子已被证伪（p=0.605），但那是全局 cap 命题；单品级 limit 折让是不同命题，未被验证过。
9. **恐慌族 0.3 仓位的置信度没进公式**：panic 期望 100% 来自单一事件簇（独立事件 2/3）——A 通道纪律只锁参，仓位本身按事件指纹定的，但"样本不完整"这个事实没有在仓位/期望标注里体现。

**D. 持有/退出层**
10. **口径错位**：单品建议持有期（panic 14d / accumulate 21d）与组合层 hold21 不一致；时间型退出已被证伪（−73pp）→ hold21 是组合最优，但单品层 hold_guidance 文案没跟着统一。

**E. 样本/验证层**
11. **三套基线混用**：HIST-FULL 317（96 池冻结）/ CLEAN-CUR 230 / HQ 189（3 年 180 池）——研究探针口径不统一，结论可比性靠人工对齐。
12. **事件依赖**：panic 族期望 100% 事件簇，干净样本 0——"恐慌共振 14d 100%/+48"本质是炼金事件指纹，单事件泛化风险由 A 通道 2/3 计数兜着，但期望标注层不展示这个事实。
13. **幸存者偏差（无对应假设，仅登记）**：180 品都是"活到今天"的品，品级留出集不可能（decision-log V1），live pilot 是唯一品级验证——大盘引擎帮不了这项，登记为长期约束。

**F. 数据层（已知、不列入本期研究）**
13. 求购历史 3 年回填仅部分品；在售量单源（假挂单/对倒虚缩无免疫）；池排除贴纸/角色/手套/箱（用户裁定）。这些是数据/池约束，不是本方案要解的引擎问题。

## 四、执行顺序与纪律

1. 本方案批准；
2. **第一批（决策层，证据已指认）**：P1（S1 指纹）→ P3（S3 base 拆解）→ P2（时期特征注入）——这三条直接对着引擎唯一负增量时期和最大 alpha 来源；
3. **第二批（独特性+结构层，原则 0 优先）**：**P13（独特性全景挖掘，扩表先行）→ P11（逆市走强指纹，fixture 用 P13 挖掘结果复核扩增）→ P12（market_weak 豁免）**→ P4（相对强度）→ P5（共振度）→ P6（deep_value 重验）；
4. **第三批（仓位/展示）**：P7（单品级折让，预期证伪但干净实验）→ P8/P9/P10（口径与标注）。
5. 纪律：每探针先预注册判据再跑；候选落地一律发射口径三关（组合级+前后半段+置换）；正负结果全部入 decision-log；不触碰已证伪结论（时间退出、组合层时期乘子）。
6. **独特性护栏（原则 0 的验收条款）**：任何大盘帮助候选落地前，必须附加回归测试——在逆市 fixture（2026-06-20~07-11 霸意大名/异星世界 + 抽象派/合纵窗口）上，引擎输出不得比基线更保守（不得吞掉独立强势品的买入/持有信号）；护栏不过，候选不得落地。护栏本身进冒烟测试。
