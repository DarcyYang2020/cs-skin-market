## 一、失败教训提炼（阶段0 + 阶段1）

| 编号 | 失败 | 教训 |
|---|---|---|
| L1 | period 时期标签 S3 从 train 63.6% 漂到 test 19.2%（44pp） | 时期是**事后标签**（chg180×chg30），不是驱动见底的因果变量 |
| L2 | 单特征（pct/z/chg3/supply30/rs30）置换 p=0.135 | 单特征「水平」无稳定信号 |
| L3 | 目标 P(fwd14>0) 全局 baseline ≈55% | **目标太弱**，区分度天然低（55% 样本都涨），信号被淹没 |
| L4 | 加维度细分 = 置换不显著的过拟合 | 控制复杂度，少而精特征 + 正则化 |

## 二、第一性原理假说（CS 皮肤「见底」的微观机制）

- **P1 供需转向共振**：见底 = 供给收缩（买家收货）+ 价格止跌（卖压衰竭）+ 买盘进场（求购价升/价差收窄）三者**共振**，单看任一维都只是噪声。
- **P2 横截面相对位置 > 绝对位置**：某品相对同池的**相对**超跌分位，比绝对分位更有信号（L3 的横截面版本——市场的整体水位是噪声，品与品的相对位置才是 alpha）。
- **P3 目标要「显著反弹」而非「微涨」**：P(fwd14>+5%) / P(fwd14>+10%) / P(跑赢大盘) 比 P(fwd14>0) 更有区分度，更贴合「见底可收货」语义。
- **P4 二阶特征捕捉拐点**：跌速衰减、供给收缩加速度、分位变化速度等「变化的变化」比「一阶水平」更接近「见底」。
- **P5 事件窗分离**：正常期的「阴跌见底」与黑天鹅期的「V 型反弹」是两套规律（AM 已证 P 期黄金坑是事件偏差），混在一起互相污染，应分开建模。

## 三、方案矩阵（预注册，分批）

| 批次 | 方案 | 第一性原理 | 目标/特征/方法 | 预注册判据 |
|---|---|---|---|---|
| 1 | **B1 目标重定义** | P3 | 目标换 P(fwd14>+5%) / +10% / 跑赢大盘，重跑 period+单品特征基线 | 新目标下 period 基线 AUC 显著 > 旧目标（0.5 附近），或单品特征 AUC ≥ 基线+0.02 |
| 1 | **B2 见底共振指数** | P1 | 合成特征 = 供给收缩 + 止跌(no_new_low2) + 3日转涨 + 价差收窄 的联合计数（0-4） | 共振指数单调性：计数越高 P(fwd14>+5%) 越高，且跨切点稳定 |
| 2 | **B3 横截面相对分位** | P2 | 特征 = 某品 pct 相对同池当日 pct 的秩分位 | 相对分位 AUC 显著优于绝对分位，跨切点稳定 |
| 2 | **B4 二阶特征** | P4 | 特征 = pct 变化速度、supply 变化加速度、chg 的二阶 | 二阶特征 AUC ≥ 一阶基线+0.02 且置换 p<0.05 |
| 3 | **B5 A 模型（正则化分类器）** | L4 | 逻辑回归 L2，严格 walk-forward，λ 用 train 内部 CV 选 | 验证段 AUC 稳定提升且校准不劣化 |
| 3 | **B6 换切分（时期/事件窗交叉验证）** | L1/P5 | train/test 按时期留一 + 事件窗分离 | 跨时期/跨事件窗方向一致 |

## 四、迭代纪律

1. 每方案先预注册假说 + 判据再跑；样本内只出候选，落地须样本外/live pilot。
2. 「换数据/方法/切分」是合法迭代；「在同一批样本上调参凑过门槛」是红线。
3. 正负结果一律登记 decision-log；失败教训回流到本文第一节。
4. 引擎/展示代码在③审计通过前不动；本轮全部是只读研究探针（`_exp_*.json`）。
