# 单品级短期期望信号 · 预注册设计（2026-08-18，研究版）

> 目标：解决系统**滞后**与**上升期收货难**——均线/周期天然滞后，本信号用「领先、非滞后」特征，
> 让用户在单品分析随刷新时**实时看见**「这品 7d/14d 期望是否已转正、是否快见底」，从而提前布局。
> 反过拟合纪律：本文方法/特征/配方/门槛全部**先注册后跑**，样本内结果只产出「候选」，落地须样本外或 live pilot。

## 一、架构收敛（两个入口，吸收其余散乱入口）

系统只保留两个决策入口：

| 入口 | 回答的问题 | 地位 |
|---|---|---|
| **融合决策**（现有） | 「这品过没过守卫/路由，能不能买」 | 主，不动 |
| **单品级短期期望**（本信号，新） | 「这品现在 7d/14d 会怎样，见底没」 | 辅，随单品分析实时刷新 |

**被吸收/降级的散乱入口**（语义统一为「这品、现在、短期」，不再各自为政）：
②时期级当下期望、族特征卡、供给三态、F 判别、期望徽章（已下架但链路仍在）、C 类全局期望、独特性状态行。

## 二、信号定义与 target（主次预注册）

输出（随单品分析刷新，四个数一起给，用户自行读）：

- `E[fwd7]` / `E[fwd14]`（短期期望值，%，扣 2% 双边）
- `P(fwd7>0)` / `P(fwd14>0)`（转正概率）

配套「转正」标注：当 `P(fwd14>0)` 与 `E[fwd14]` 双双转正时提示「短期期望转正，可关注收货」。

**target 主次（预注册）**：`P(fwd14>0)` 为**第一主指标**，`P(fwd7>0)` 为**第二确认**（14d 更稳、更贴合收货语义；7d 做快确认）。

## 三、特征池（预注册固定，刻意不用均线/周期/TH 均线分量）

**市场底座（最小化，做环境门）**：`period`（五时期）、`period_days`（进入第 N 天）、`mchg30`（大盘 30 日）。

**单品领先特征（核心增量，全部来自系统已有指标或可现算）**：

| 类 | 特征 | 系统来源 | 为什么「领先」 |
|---|---|---|---|
| 位置 | pct（90日分位）、z | valuation.py | 直接量「跌到哪了」，不看均线 |
| 反转 | chg3（3日动量）、no_new_low2、跌速衰减 | 超跌例外已用 no_new_low2+chg3d | 反转是拐点最前兆 |
| 供给 | s7/s30 在售收缩比、supply_change_30d | supply.py | 挂单存量实时，不滞后 |
| 求购 | Δspread（5日价差变化） | bid_history（3 年直连） | 实时求购价，最敏感买盘意愿 |
| 相对强度 | RS30（单品30d − 大盘30d） | P4 相对强度 | 识别「大盘阴跌里的独立强势」 |
| 独特性 | 逆市走强/低相关/供给锁仓指纹 | 独特性七形式 F1/F3/F6 | 领先见底/供给锁仓的非均线证据 |
| 波动 | 波动率 regime | analyze_probability | 高波见底 vs 阴跌的区分 |

> **独特性七形式在此从「展示历史胜率」降级为「候选预测特征」**——这是两题合流的落点。

## 四、模型 B：条件匹配 + 收缩（预注册）

1. 重建宇宙面板（`_exp_universe_panel_v2.json`）：180 品 × 3 年 (item, day)，补 fwd7/chg3/no_new_low2/跌速衰减/Δspread/RS30，存原始值不分桶。
2. **贪心顺序条件**（固定顺序）：`period → period_days → [单品领先特征按预注册顺序]`。
3. **收缩**：`Ê = λ·cell + (1−λ)·mean_period`，`λ = n/(n+k)`，**k=20 预注册**；n<5 回退 `mean_period`。
4. 输出 4 个数 + n + 置信带，实时按当前品状态查表。

## 五、候选配方（预注册固定，不是自由网格）

「找最好信号」拆成有假说依据的固定配方，先写「为什么可能领先」再跑：

| 配方 | 条件维度 | 假说 |
|---|---|---|
| H1 | period（+period_days） | AM 基线，纯时期环境 |
| H2 | H1 + pct + z | 位置分位领先见底 |
| H3 | H1 + chg3 + no_new_low2 + 跌速衰减 | 反转形态领先 |
| H4 | H1 + s7/s30 + Δspread | 供给+求购实时证据 |
| H5 | H1 + RS30 + 独特性指纹 | 相对强度/独特性（大盘阴跌里挑独立强势） |
| H6 | H1 + 组合（逐维累加，贪心顺序） | 全特征最优（仅作观测，不与 H2-H5 同权重判过拟合） |

## 六、测试纪律与验收门槛（红线）

1. **多切点 walk-forward**（≥4 切点，对齐 X 条目已验证稳定切点）：2024-07 / 2024-10 / 2025-02 / 2025-08-10。训练段拟合、验证段只打分，**跨切点都稳才算数**。
2. **决策指标，不用 RMSE**：主指标 = 验证段 **AUC**（`P(fwd14>0)` 分类）+ **校准度**（Brier/可靠性曲线）；辅指标 = 「P>0.5 子集」的 fwd14 净收益 vs 全宇宙基线。
3. **领先度（报告，不设硬门槛）**：均线拐点 = MA7 上穿 MA30；度量本信号「转正」比均线拐点平均提前多少天 + 领先窗口收益，**仅报告**，供用户看痛点解决没解决。
4. **验收硬门槛（四条，防过拟合底线）**：
   - 验证段 AUC 相对 H1（period 单因素）基线**显著提升**（预注册 ≥ +0.02 且置换 p<0.05）；
   - 多切点方向一致、不 flip；
   - 校准度不劣于基线；
   - 前后半段一致。
5. **选择规则**：过全部门槛的配方里选**跨切点方差最小**（最稳）者为候选；一个都不过 → 诚实登记「单品特征对短期预测无增量」，**禁止换特征/换切点/换指标去凑**。

## 七、可持续优化（第一等公民，不是一次性结论）

- **面板版本化**：`_exp_universe_panel_v2.json` 带 schema 版本 + 特征清单 + 数据截止日，历史面板不覆盖、可回放。
- **配方登记制**：每条配方预注册假说 + 判据 + 产物路径，正负结果进 decision-log，下一批的起点是上一批的台账。
- **三通道驱动**：B 通道（样本外 ~2027-04 重验）/ C 通道（上线后「转正提示」真实 7d/14d 表现监测，连续劣化触发重拟合）/ live pilot（小仓真实成交）。
- **信号版本**：给本信号单独 version，每次优化 bump 一次，可追溯「哪一版预测力如何」。

## 八、阶段划分

- **阶段 0（本轮）**：重建/扩展宇宙面板 → 跑 H1（period 单因素）的 AUC/校准基线 → 量出「②目前到底有多少预测力」。
- **阶段 1**：加单品领先特征 × 时期（H2-H6），看验证段 AUC/净收益是否过门槛。
- 正优化 → 交③审计；否则证伪登记。
