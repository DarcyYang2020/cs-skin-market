# CS2 饰品市场交易策略手册

> 版本: v4.0 | 更新: 2026-07-16
> 基于项目内置分析引擎：趋势健康度 + 估值宫格 + 融合决策 + 庄盘识别

---

## 策略核心前提

完全适配 CS2 市场的以下特征：
- **强周期、事件驱动**：箱子上下架、Major赛事、炼金机制变更主导行情
- **T+7 锁仓**：买入冻结7天，无法日内T+0
- **流动性分层**：热门武器皮 vs 冷门收藏品，出货难度天差地别
- **情绪超涨超跌**：散户追涨杀跌严重，超买超卖是常态

策略完全基于产品内置指标制定，拒绝主观猜涨跌：
- **90日百分位** → 判断价格位置
- **Z-score** → 判断偏离程度
- **趋势健康度(TH)** → 判断趋势质量
- **流动性评分** → 判断出货难度
- **周期阶段** → 判断行情阶段
- **庄盘概率** → 识别人为操控

---

## 一、核心入场标准

### 硬性门槛（同时满足）

| 条件 | 阈值 | 含义 |
|---|---|---|
| 90日百分位 | ≤ 30% | 价格处于近三月低位，泡沫出清 |
| Z-score | ≤ -1.5 | 短期非理性超跌，反弹修复需求强 |
| 趋势健康度 | ≥ 60 | 趋势转强确认，非下跌中继 |

### 选品避雷（任一触发则放弃）

- 趋势健康度 < 40（下跌趋势不抄底）
- 流动性评分 < 30（有价无市，卖不掉）
- 庄盘概率 > 60% + 趋势向上但量价背离（虚假多头）
- 处于版本利空周期（炼金改版、大批箱子上新）
- 纯溢价炒作品（高贴纸溢价、冷门天价皮）

## 二、分批建仓策略（适配 T+7）

| 阶段 | 条件 | 仓位 |
|---|---|---|
| 首次底仓 | 百分位 ≤ 30%，TH ≥ 60 | 轻仓试错 |
| 二次加仓 | 价格横盘不创新低，TH 持续 ≥ 60 | 加至半仓 |
| 加至目标仓 | Z 值触底回升 + 量价配合健康 | 加至目标仓（单票总敞口≤30%，与 F-3.7/单票敞口提示一致） |

**持有周期**：15-45 天（适配箱子/赛事/热度轮动周期）

> 2026-08-09 口径修正：完整建仓/补仓纪律见 `references/position-building-strategy.md`（第一性原理定稿）；
> 旧「满仓」表述作废——单票总敞口上限 30%（组合层提示口径），建仓批次按上限缩放。

## 三、止盈止损规则

### 止盈（二选一即离场）

| 类型 | 条件 | 操作 |
|---|---|---|
| 稳健止盈 | 90日百分位 ≥ 65% | 分批落袋 |
| 激进止盈 | Z-score ≥ +2.0 | 全部清仓 |
| 极端泡沫 | 百分位 > 95% + Z > 2.5 | 强制清仓（不受 TH 修正） |

### 止损

| 类型 | 条件 | 操作 |
|---|---|---|
| 技术止损 | 创 90 日新低 | 果断减仓 |
| 事件止损 | V社机制更新 / 炼金改版 / 箱子下架取消 | 无条件清仓 |

### 补仓/止损矩阵（F-3.7 新增，2026-08-09）

旧固定止损（-25% / 90 日新低）已由状态矩阵替代（持仓管理展示层），完整理论 + 回测见 `references/stop-loss-strategy.md`：

| 状态 | 判定条件 | 动作 |
|---|---|---|
| 供给扩张 | 单品在售量 30日 +5% | 全止损（结构性恶化） |
| 恐慌深跌 | 大盘 30日 ≤-15% | 不止损 → 转补仓评估 |
| 阴跌中继 | 大盘 30日 -15%~-5% | 减半止损 |
| 大盘上涨段 | 大盘 30日 >5% | 不止损 |
| 中性 | 大盘 30日 -5%~+5% | 不止损 |

触发线：浮亏≥-15% 评估；补仓仅「恐慌深跌 + 单品供给收缩」，倒金字塔 3:2:1、单批≤15%、总敞口≤30%。

## 四、周期轮动策略

贴合 CS2 四大市场周期：

| 周期阶段 | 特征 | 操作 |
|---|---|---|
| **吸筹期** | 低百分位、负 Z 值 | 只买不卖、分批囤货 |
| **洗盘期** | 震荡反复、均线缠绕 | 不加仓、不止损、持有卧倒 |
| **拉升期** | 百分位抬升、Z 值转正、量价配合 | 持有为主、临近高位减仓 |
| **出货期** | 高百分位、高正 Z 值 | 只卖不买、空仓观望 |

关键区分：小幅度回调（MA7<MA30 但乖离 ≤ 3%）判定为洗盘/换手，非出货。

## 五、品类优选

| 优先级 | 品类 | 特征 |
|---|---|---|
| 1 | 一线热门武器皮 | 流动性最强、波动稳健、适合中线囤货 |
| 2 | 当期主流胶囊/箱子 | 周期属性极强，下架预期驱动确定性涨幅 |
| 3 | 中端热门手套/刀具 | 资金关注度高，适合波段套利 |
| ⚠️ | 冷门溢价皮/高贴纸皮 | 溢价回撤无支撑，避雷 |

## 六、风控铁律

1. **永不重仓单一品类**：分散持仓，规避版本利空系统性踩踏
2. **只用闲钱**：CS2 周期磨底时间长，杜绝资金压力低位割肉
3. **不做超短线**：T+7 机制限制，频繁交易 = 反复亏损手续费
4. **敬畏规则风险**：V社机制改动 > 一切技术指标，利空面前无抄底
5. **大盘出货期全局降仓**：大盘融合决策 = 减仓/观望时，所有单品建仓信号降级

## 七、策略与产品功能的对应关系

| 策略需求 | 对应产品模块 |
|---|---|
| 买点判断 | 90日百分位 + Z-score + 趋势健康度 |
| 趋势质量 | 趋势健康度六维度（持续性/陡度/均线/量价/异常/支撑压力） |

| 仓位建议 | 估值宫格（3×4）+ 融合决策 |
| 止盈止损 | 智能点位提示 + 极端估值保护 |
| 风险规避 | 事件前瞻修正 + 信号冲突检测 |
| 宏观约束 | 大盘融合决策 → 全局仓位上限联动 |

## 八、一句话 SOP

> 30%分位以下 + 趋势健康 ≥ 60 + 高流动标的，分批囤货，周期持有至 65%分位或超涨回落止盈，
> 高位绝不追高，利空无条件避险，大盘出货期全局降仓，只做中线周期套利。

## 九、实盘修正（v4.3 新增）

### 1. 交易摩擦扣费
悠悠有品手续费 1%，分析引擎的「综合性价比优秀/中等」推荐已自动附加扣费提示。
短线交易（7 日内）实际成本更高，不建议短线频繁操作。

### 2. 品类差异化阈值
不同品类波动率差异大，全局统一百分位/Z-score 阈值不适用高波动品类：

| 品类 | 入场百分位 | 入场Z-score | 止盈百分位 | 止盈Z-score | 原因 |
|---|---|---|---|---|---|
| 默认（步枪/手枪等） | <=30% | <=-1.5 | >=65% | >=+2.0 | 基准 |
| 收藏品 | <=20% | <=-2.0 | >=60% | >=+1.5 | 高波动，需更深折扣 |
| 胶囊 | <=20% | <=-2.0 | >=60% | >=+1.5 | 高波动，需更深折扣 |
| 手套 | <=35% | <=-1.2 | >=70% | >=+2.2 | 低波动，可容忍稍高分位 |
| 匕首 | <=35% | <=-1.2 | >=70% | >=+2.2 | 低波动，可容忍稍高分位 |

### 3. 统计口径统一
全系统偏离指标统一为 MAD-Z（中位数绝对偏差），替代传统标准差 Z-score：
- 计算公式: (current - median) / (MAD * 1.4826)
- 优势: 对异常值更鲁棒，不会因单日暴涨暴跌导致 Z 值剧烈失真

### 4. 事件风险折价
重大 V 社规则更新自动压低大盘趋势健康分：
- 系统性利空: 趋势健康分 x0.7
- 品类级别利空: 趋势健康分 x0.85
- 系数由 market_macro.event_risk_coefficient() 按日期窗口计算
