## 一、现有引擎结构（五层）

### 1. 数据层（pipeline/）
| 数据 | 来源 | 覆盖 |
|---|---|---|
| 大盘指数/K线 | csQAQ HTTP API | market_index 2023-11 起，993 天 |

| 情绪 | csQAQ greedy[] | 真实 2026-06-03 起 60 天；此前价格代理 |

### 2. 大盘引擎（index_analysis.py + market_th.py + market_macro.py）
- 点位（90日 pct/z）、概率、周期、性价比评分、多因子概率
- **趋势健康度 TH（0-100）**：持续性24% / 陡度24% / 均线19% / 量价18% / 缺口15%
- **融合决策**（market_th）：pct×TH×周期×方向×情绪 → buy/watch/avoid + global_position_limit
- 牛熊动态 TH 阈值（v5.2）、熊市过滤器（microTH/恐慌抛售/反弹衰减/安全网）
- **市场状态六态**（market_regime，I-1 展示层）：贪婪禁入/V型底区/阴跌中继区/恐慌浅跌/中性企稳/弱市观望

### 3. 单品引擎（item_analysis.py，核心串行链）
十大模块（估值/周期/流动性/概率/价值/庄盘/趋势健康/融合决策/价格区间/距买点），
buy 信号由**一串 P0/P1 顺序 if 块**产出：

| 通道 | 触发概要 | 仓位 | 家族 |
|---|---|---|---|
| P0-1/1b/3/4 | 守卫：大盘弱/存世量<3000/半山腰/飞刀未止跌 | — | 闸门 |
| P0-2 | 7 天同品去重 | — | 闸门 |
| P0-5/7 | 恐慌共振升级（sent≥75+microTH≥60+单品大盘过滤） | 0.30 | panic |
| P0-7b | 周期吸筹但大盘未深跌 → 深度回调低吸 | 0.10 | accumulate 变体 |
| P0-8 | 深值+大盘企稳（深值企稳·分批建仓） | 0.10 | deep_value |
| P0-9 | 恐慌退潮·深跌止跌 | 0.10 | panic 退潮 |
| P1-0 | 供给收缩·启动前吸筹（S3，C1 趋势腿） | 0.10 | supply_accum |
| 超跌例外 | pct≤15+z≤-2+跌速衰减（回放窗口未触发） | — | oversold |

**问题诊断**：P1-0 是「watch/avoid 时后置追加」的补丁块（item_analysis.py:1417），
再往后加 S2 回踩/牛市动量就是 if-else 拼装 → 两套逻辑分裂，正是本轮要解决的。

### 4. 批量扫描/组合层（batch_scan.py + portfolio_risk.py）
- 自选批量扫描：市场环境条（六态）+ 距买点列 + 排序 + 持仓个性化建议
- 组合闸门（B1）：回撤熔断 10% + 单票敞口提示 30% + 并发 cap 0.8（提示层）

### 5. 展示层（webapp/main.py + templates）
大盘仪表盘 / 单品报告（距买点+期望统计条+买点距离）/ 持仓 / 批量扫描 / 执行复盘

## 二、项目原则与迭代原则

### 三原则（project-principles.md v1.0）
1. 破除散户魔咒：恐惧/贪婪 → 计算符号
2. 数学模型代替主观：正期望交易，胜率仅辅助
3. 止损是付费买正确概率：看错时少亏

### 落地工作流（硬性）
- **算法改动必须数据先行**：先回测验证（起点 2025-11-02，五合一后口径），再改码
- **优化目标**：更高胜率 + 更高期望/盈亏比；熊市侧重 14d
- **风控参数**：硬性参数必须组合回测先行，否则只做提示
- **信号族审计**：展示必须带独立事件数；新信号上线需 A2 三件套（walk-forward+聚类+置换）
- **工程**：中文用临时 .py 写（避免 PowerShell GBK）；改后跑 test_smoke

### 迭代闭环（iteration-roadmap.md）
执行 → 学习/试错 → 提炼新思路 → 映射为迭代项 → 更新 roadmap（版本+日期）。
当前 v4：第一批完成；第二批（等数据）含 I-6/7/8/9/10、J-2/3。

## 三、统一大脑方案（两条腿 → 一个决策核心）

### 3.1 核心思想
不做「恐慌→抄底引擎、牛→趋势引擎」的两套引擎拼装；
而是**一个决策核心**：信号族库注册 + 状态桶条件期望表 + 统一排序决策。
双腿 = 同一大脑在不同状态下的信号族，可并存（恐慌+深跌时深值企稳与 S3 吸筹同时候选，由期望定主次）。

### 3.2 架构
统一决策核心（unified_brain）
- 输入：市场上下文(TH/sent/cycle/chg30/drop21) + 单品特征(pct/z/th/供给/量能/存世量)
- 状态桶层：6 桶（引擎口径，见 3.3）
- 信号族库（注册制）：
  - panic共振(0.3) / panic退潮(0.1) / deep_value(0.1) / supply_accum(0.1)
  - accumulate低吸(0.1) / base低位低估(0.2) / (未来)S2回踩 / 牛动量
  - 每族 = {触发条件, 状态桶限制, 期望表引用, 仓位, 去重键}
- 决策函数：候选生成(各族触发) → 桶查表(期望) → 排序+同日同品去重(取最高期望族)
  → 单一 action + position_limit + 期望标签
- 闸门层（解耦）：存世量/7天去重/飞刀确认/组合熔断/单票敞口

### 3.3 状态桶（6 桶，引擎口径——修正展示层 80 分偏差）
| 桶 | 判定（引擎口径） | 对应行情 |
|---|---|---|
| 恐慌深跌 V型底 | sent≥75 & chg30≤-15 | 2026-05 |
| 恐慌中跌 阴跌中继 | sent≥75 & -15<chg30≤-5 | 2026-07 |
| 恐慌浅跌 | sent≥75 & chg30>-5 | — |
| 中性企稳 | sent<75 & TH≥45 | 修复/震荡/小牛（2026-02、2025-11~01） |
| 弱市观望 | sent<75 & TH<45 | 阴跌非恐慌段 |
| 贪婪禁入 | sent≤30 | 强牛末端（2025-04~05 顶部） |

**口径发现**：展示层 market_regime 用 sent≥80 判恐慌，而引擎 P0-7 恐慌共振是 sent≥75 →
统一大脑状态桶必须以引擎口径（75）为准，展示层标注同步修正（I-1 遗留）。
### 3.4 条件期望表（阶段1研究产出，data/unified_brain_expectancy.json）
全窗口 2025-01-01~2026-08-05，池A=96老品，581 buy 信号（data/item_backtest_full_2025.json）：

| 信号族 | 桶 | n | 独立事件 | 14d net | 30d net | 判定 |
|---|---|---|---|---|---|---|
| panic 共振+退潮 | V型底/恐慌边缘 | 92 | 2 | 84~100% / +19~51 | 76~82% / +14~41 | 单事件簇(5月)，J-2未达 |
| deep_value | 中性企稳 | 252 | 27 | 46.8% / +3.1 | 50.8% / +9.2 | 最广信号源但14d平庸 |
| deep_value | 弱市 | 50 | 8 | 48% / +5.7 | 73.8% / +30.2 | 弱市30d反而好 |
| supply_accum | 中性企稳 | 108 | 8 | 63% / +8.2 | 68.5% / +24.2 | 趋势腿主场景，单簇88.9% flag |
| supply_accum | 弱市 | 47 | 5 | 53% / +7.8 | 76.6% / +16.1 | |
| base/低吸 | 中性企稳 | 24 | 9 | 54.5% / +18.5 | 45.5% / +15.7 | 分散，样本小 |

**数据启示**：
1. deep_value 是系统最广信号源（252@中性企稳），但 14d 46.8% 期望平庸——统一大脑应对该场景降低优先级/期望标注「平庸」，或叠加筛选（如单品 TH 门槛、chg30 方向）。
2. supply_accum 中性企稳 30d +24.2 是趋势腿主证据（8 事件仍单簇 88.9% 集中在 2 月，事件级未达标）。
3. panic 事件数仅 2（5 月单次），0.3 仓位依赖单一事件——J-2 前保持轻仓纪律或标注。
4. 弱市桶 deep_value 30d +30.2 提示：恐慌边缘+TH<45 的深值信号 30d 有超额（8 事件）。

### 3.5 决策规则（v0 草案）
```
对每个单品：
  candidates = []
  for fam in registry:
      if fam.trigger(单品特征) and fam.bucket_allowed(状态桶):
          exp = fam.expectancy(状态桶)   # 期望表查表
          candidates.append({fam, exp, limit})
  if not candidates: action=watch/avoid（走现守卫链）
  # 同日同品多族：取最高期望族（防双计）
  best = max(candidates, key=exp排序)
  # 事件数纪律：该族该桶事件数 <3 → 期望标签加「样本不足」警示
  output: action=buy, label=best.family, position_limit=best.limit, expectancy=best.exp
闸门层后置：P0-1/1b/3/4 守卫 + B1 组合闸门（顺序不变）
```

### 3.7 风险与防过拟合

- 每族每桶按事件数门槛展示/降权（J-2），单事件簇不调参
- 阶段2 只重构决策框架（排序/去重），不新增触发参数；参数调整需阶段2对比通过
- 情绪代理失真（2025 上半年）仅影响 sent 分桶，TH/chg30/cycle 结论不受影响

## 四、阶段2 决策层回测结论（2026-08-06）

脚本：references/unified_brain_stage2.py → data/unified_brain_stage2.json
方法：581 信号按日期 anchor=0.7 切分（cut=2026-02-23，train 300 / test 281）；
train 估计「族×状态桶」net14 期望表（6 格 n>=3），test 段应用决策层改造（只改仓位/排序，不改触发条件）。

| 方案 | test 14d wavg | test 30d wavg | 说明 |
|---|---|---|---|
| baseline（现引擎原仓位） | +21.43 | +17.43 | 基线 |
| planA 期望分档仓位 | +24.82 | +19.97 | 表面提升 +3.4pp |
| planB planA+深值降权 | =planA | =planA | deep_value@中性企稳 train exp=6.09≥5 未触发 |
| planC planA+同日cap0.8 | +17.64 | +17.16 | cap 剔除高期望恐慌信号 → 反而下降 |

### 4.1 稳健性检验（关键）
- **去掉 panic 后**：test 190 非恐慌信号 baseline wavg14 **+5.06** vs planA **+3.30** → planA 反而更差 -1.76pp。
  整体 wavg 提升完全来自「panic 保持 0.3 + 其他族降仓 → panic 权重集中」，而 panic 恰好是 5 月单事件（test 段表现极好）。
- **tier 档位敏感性**：scale 0.5/1.0/1.5/2.0 → wavg14 30.43/24.82/21.15/18.56，随档位缩放剧烈变化 → 机制不稳定。
- **根因**：train 期望表在 test 段漂移（deep_value@中性企稳 train exp=6.09，实际 test 表现更高，降仓反而伤害）；
  条件期望跨时段不稳定，当前样本（族×桶事件数少：panic 2 / supply_accum 8 事件）不足以支撑期望排序。

### 4.2 阶段2 结论（已证伪项 + 保留项）
- **已证伪（当前数据下不可落地）**：期望分档仓位 / 期望排序 / 同日 cap 剔除——均未通过样本外检验，
  属「看着赢实则自证」的又一案例（A2 教训）。等 J-2 事件数门槛（≥3~5 独立恐慌事件 + 中性回升段）后重估，列入第二批。
- **保留（架构价值成立）**：信号族注册制 + 状态桶 + 单一决策输出的**工程统一**仍要做——
  它解决「两套引擎分裂」的可维护性问题，但不承诺短期期望提升；阶段 3 聚焦架构重构，不做仓位分档。
- **过程发现**：deep_value@中性企稳是全系统最广信号源（252 信号/27 事件），14d 46.8% 期望平庸是**触发条件层**问题，
  不是仓位层能解决的——留待更多样本后做条件筛选研究（I-6 关联）。
