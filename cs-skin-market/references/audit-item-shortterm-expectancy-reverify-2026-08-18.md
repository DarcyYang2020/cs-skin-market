## 3. 独立复算（stage9 逐行数据，36654 条 = stage8 各期 val_n 之和）

### 3.4 前后半段一致

样本内(stage6 cut1) → val：P 23.81→23.31、S1 7.36→16.31、S2 4.91→6.16——**方向一致，S1/S2 val 更强**；S3 2.09→2.09（spearman 反转 → 剔除）；S4 无信号。⚠️ 注意：stage6 三 cut 为嵌套窗口（n 随 cut 后移递减，非独立样本），P 的 cut1 n=4095 与 val 4004 高度重叠——fit 侧独立证据弱，但 val 侧（真正的样本外）是干净测量。

### 3.5 stage7 可溯源性

仅 P 的 D_real=23.81 与 stage6 cut1 对齐；S1/S2/S3/S4 的 D_real（4.63/2.04/6.31/0.45）为全样本合并口径，**无法从给定产物独立复算**；且产物无 seed/p 计算方法字段（规格声称 seed=42）。→ 非阻断：本审计的独立 val 段置换（§3.3）提供了更强的显著性证据。

## 5. 裁决：通过（有条件）

### 通过依据
1. 审计#1 五项驳回点全部回应且预注册判据已落盘（修订规格在盘）；
2. 发射侧样本外核心主张经独立复算成立：P/S1/S2 单品特性在 val 段提升排序（spearman 0.02→0.20 / −0.03→0.16 / −0.08→0.07 量级；topbot +23.3 / +16.3 / +6.2pp）；
3. val 段独立置换统计显著（P/S1/S2 p≈0.002）；
4. 前后半段方向一致（S1/S2 样本外更强）；
5. S3 趋势特性样本外失效（spearman 负）如实剔除、S4 无信号正确排除——**证伪被诚实记录而非掩盖**，符合反过拟合纪律。

### 落地条件（必须满足，缺一即不成立）
1. **保持纯展示**：ENGINE_VERSION 不 bump；`t_shortterm_expectancy`「不进决策」断言实现并通过冒烟测试；
2. **S3/S4 不得启用单品特性**（按修订规格）；任何范围扩大（重启 S3 趋势、新增 S4 特性）须重新过发射侧检验 + 本审计；
3. **查表产物** `build_shortterm_table.py` 用 walk-forward train（SPLIT 前）拟合、版本化（schema 版本 + 数据截止日）；查表口径须与 stage8/9 一致（base 定义统一）；
4. **可复现性修补**：stage7 补记 seed / n_perm / p 计算方法字段；stage9 与 stage8 的 base 口径统一（pred_base 定义说明——本审计发现 stage9 的 pred_base 为时期级常数，stage8 的 spearman_base 无法从 stage9 复现）；
5. **P 期 2 事件外推限制**（规格 §六 已声明）：落地后由 B 通道（~2027-04）重验或 live pilot（C 通道月度胜率/期望监测自动熔断）承担；
6. 残留选择泄漏提示（period→trait 映射在 stage6 嵌套窗口含 val 数据上选定）：trait 分数定义在初版规格已预注册，val 段测量为真实样本外；残余风险由条件 5 的监测覆盖。
