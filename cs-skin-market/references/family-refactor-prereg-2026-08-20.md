# 族划分完全重构 · 引擎独立全量扫描（预注册判据）

> 决策（2026-08-20 用户裁定）：放弃以 374 引擎信号为依据的族划分（有偏样本——只含旧引擎开火的时刻），改为**引擎独立**——从 3 年原始行情直接反推真实市场结构，产出「最精确的族划分 + 盲区清单」。
> 本文是**预注册判据**：特征集 / 切分方法 / 正期望阈值 / 前向窗口全部在跑扫描前锁定，跑后不改。扫描产出 = **样本内候选**，仍需「族开回放 → 四关 → ③审计 → 样本外/live」才可落地。

## 一、数据源与样本

- 库：`data/replay_cycle_win.db`（DATA-1 后 240 品 3 年历史）。
- 品池：除贴纸（印花）、角色、2 污染品（`AK-47 | 流金王朝`、`挂件 | 丁烷拍档`）外的 **232 品**。
- 字段（已核对 schema）：
  - `price_history`: `item_id, date, price_rmb, volume_day, volume_total, in_sale_count`
  - `market_index`: `date, value, change_7d, mood`
  - `macro_history`: `date, greedy_index, card_price`（**greedy_index 仅 2026-02 起覆盖**；2025 年情绪缺失）
- 样本单元：**item-day**（每品每日一条），warmup 后约 232 品 × ~750 日 ≈ 17 万条。

## 二、特征集（预注册，锁定）

对每个 item-day 计算以下特征，定义一次性写死、跑前不改：

1. **位置/估值**：`pct` = 价格在近 90 日窗口的分位（0–100）；`z` = 价格 z-score（90 日窗口均值/标准差）。
2. **单品动量**：`chg7` / `chg30` / `chg90` = 价格 7/30/90 日涨跌幅（%）。
3. **大盘语境**：`mchg7` / `mchg21` / `mchg30` = `market_index.value` 的 7/21/30 日涨跌幅（%）；`regime` = 大盘五时期路由标签。
4. **供给**：`sc7` / `sc30` = `in_sale_count` 的 7/30 日变化率（%）。
5. **波动**：`vol7` / `vol30` = 价格 7/30 日收益率标准差。

## 三、前向收益标签（预注册）

- `fwd14` = `(price[t+14]/price[t] − 1) × 100 − 2.0`（扣 2% 双边成本）
- `fwd30` = `(price[t+30]/price[t] − 1) × 100 − 2.0`
- 尾部不足 14/30 日的 item-day 置空、不计入统计。

## 四、结构发现方法（预注册；2026-08-20 ③审修订：双期限 + 稀有结构探针）

- **主方法**：决策树回归，目标 = `fwd14` 与 `fwd30` **各一棵**；约束 `min_leaf ≥ 200`、`max_depth ≤ 4`（防过拟合）。
- **稀有结构探针**：对 `pct` 做 20 桶等频分桶 + 低 `pct` 子空间 `min_leaf ≈ 50` 细树，专门捞稀有区域（防 `min_leaf≥200` 把稀有深值区域并进大叶而隐身）。
- **备选校验**：对 `pct` / `chg7` / `mchg21` 做等频分桶，可解释性交叉验证。
- 每个叶/区域统计：`n, win14, avg14, median14, win30, avg30`（均为净收益）。

## 五、正期望区域判据（预注册；2026-08-20 ③审修订：双期限）

一个区域在 **14d 或 30d 任一期限** 同时满足以下全套，即算「可交易正期望结构」：

1. `n ≥ 200`（样本量下限）
2. `win ≥ 55%`（**对应期限**，净）
3. `avg ≥ +2.0%`（**对应期限**，净）
4. **walk-forward 方向一致**（切点 `2025-08-10`）：拟合段（<切点）与验证段（≥切点）的**对应期限** `avg > 0` 且 `win ≥ 50%`
5. **稳健性**：剔除该区域**对应期限** forward 收益前 5% 极值后，`avg ≥ +1.0%`

通过者记录其「自然期限」元数据（14d / 30d）。

> 说明：`win≥50%`（walk-forward 段）只作地板、不作结论——验证段每区域约 60–70 条、统计功效低（±12pp）；真正功效测试在后续四关（族开回放 + 发射复算）。

## 六、引擎覆盖对照（子题②）

- 把引擎 5 个活跃族（恐慌共振 / 恐慌退潮 / 深值企稳 / 供给收缩 / 吸筹型上涨）的触发条件映射到同一特征空间，标出它们覆盖的区域。
- **盲区 = 正期望区域 − 引擎已覆盖区域**。
- 盲区清单 = 子题②的完整答案（不限于急跌型恐慌，含牛市上行段等任何漏掉的结构）。

## 七、产出 → 候选族

- 每个正期望区域 → 一个**候选族**（边界 = 区域边界）。
- 候选族仍需完整链路：预注册 trigger → 族开回放 → 四关（`a2_emission` 发射复算 + 组合级 + 前后半段一致 + 置换）→ ③审计 → 样本外 / live pilot。

## 八、反过拟合纪律

- 特征集 / 阈值 / 窗口 / 切点全部在本文锁定，跑前不改。
- 扫描结果 = 样本内候选；禁止在同一扫描样本上反复调阈值至通过。
- 落地须样本外（B 通道 ~2027-04）或 live pilot 确认。

## 九、本扫描不做的事

- 不决定最终族边界（只提出候选区域）；最终族划分仍走四关 + ③审计。
- 不直接改 `pipeline/` 或 `webapp/` 代码；只产出 `data/_exp_*.json` + 本预注册 + decision-log 条目。
