## 一、第一性原理：CS 市场建仓到底在买什么

### 1.1 定价三要素（先于任何策略）
| 要素 | 事实 | 对建仓的含义 |
|---|---|---|
| 供给刚性 | 存世量由箱子发行/停产锁定，总量近固定；在售量是唯一可变「情绪供给」（可控盘） | 便宜=市场错杀而非供给崩坏；供给扩张=结构恶化，任何位置禁买 |
| 需求周期性 | 事件驱动（Major/开箱/热度轮动），需求弹性远大于供给 | 建仓本质是「用低于未来需求的价格买入」 |
| 流动性摩擦 | T+7 锁定、挂单深度有限、双边手续费约 2% | 无法日内逃顶 → 必须分批；冷门品滑点大 → 优先流动性好的部分 |

### 1.2 建仓的本质
建仓 = 把「不确定但正期望的信号」通过 **仓位 × 批次** 压缩成可承受的风险收益曲线。
三个问题：买什么（选品）、何时买（择时）、买多少/怎么分批（仓位管理）。
**不是「找会涨的品」，而是「怎么买才不亏」**——系统的回测证明：风控贡献了主要价值，择时是次要的。

### 1.3 系统实证锚点（回测说了什么）
| 结论 | 证据 | 对建仓的约束 |
|---|---|---|
| 引擎边际价值在风控 | cap0.8：+193.3% / maxDD -9.4%；池内等权 +509.75% / -54.12%；大盘 -4.02% / -58.21% | 单票信号无稳定 alpha，仓位纪律是主价值 |
| buy 信号整体正期望 | 370 信号 14d 72.4% / +17.9%（不设常规止损） | buy 族触发即可作为建仓入口 |
| 信号族期望分化 | deep_value 252@中性 14d 46.8% 平庸；supply_accum 108@中性 30d +24.2；panic 92 信号仅 2 个独立事件 | 期望低的族更轻仓；事件数少的族必须降级/标注 |
| 大盘环境决定期望 | I-13：深值族 mchg30≥3 上涨段 14d 仅 44% 胜率 → 剔除 | 同样的便宜，环境不同期望不同；阴跌中继禁抄底 |
| 已证伪的复杂化 | 期望分档仓位 / 期望排序 / 同日 cap 剔除 / 熔断 10% 均未过样本外检验 | 建仓仓位保持「族级固定 + 简单约束」，不做复杂分档 |
| 分批有效 | 方案 C（首仓10%→跌10%加20%→跌15%加30%）hold14 资金加权 +48.13% vs 一次性按 position_limit +31.35% | 建仓必须分批，且批次节奏有正贡献 |
| 补仓只认 V 型底 | 恐慌深跌+供给收缩 win87% / +43.7%；阴跌中继/供给扩张补仓为负期望 | 补仓纪律比建仓更严：倒金字塔 3:2:1、≤3 批 |

## 二、建仓四问（推导出的框架）

### 2.1 买什么（选品）
需求弹性大 + 供给锁定 + 流动性够：
- 存世量适中（太少无流动性、太多无稀缺溢价）；
- 在售深度达标（avg7 在售 ≥15，系统流动性闸门）；
- 事件敏感（热门枪/经典皮/活跃箱）；
- 对应系统：六维评分 + 流动性闸门 + discover 池筛选。

### 2.2 何时买（择时）
在「风险已被价格消化」时买：
- 估值分位低（pct≤30 低估区）+ Z 负值；
- 供给收缩量价配合（在售减 + 价格稳/涨 = 吸筹；在售增 = 派发禁买）；
- 大盘环境允许（恐慌后 V 型底 / 企稳修复；阴跌中继、贪婪禁入禁抄底）；
- 对应系统：buy 信号族（恐慌共振 0.3 / 深值企稳 0.1 / 恐慌退潮 0.1 / 供给收缩吸筹 0.1 / 超跌反弹例外）+ 守卫链 + I-13 环境闸门。

### 2.3 买多少（仓位）
期望值近似，受三大约束：
1. 信号质量：族级 `position_limit`（引擎已产出 0.05~0.30，按价值分+情绪分级；后置族固定 0.10）；
2. 事件独立性：panic 族仅 2 个独立事件 → 0.3 仓位必须轻仓纪律/标注（J-2 前）；
3. 组合约束：并发 cap0.8 + 单票总敞口 ≤30%（`POSITION_CAP_SINGLE`，提示层）；
4. 已证伪复杂分档 → 保持简单。

### 2.4 怎么分批（执行）
T+7 决定必须分批，把一次性判断风险摊成时间风险：
- 首仓：轻仓试探（方案 C 首仓 10%，可更轻），只认 buy 族触发；
- 加仓：较首仓价再跌 10% 加 20% → 再跌 15% 加 30%（方案 C 节奏 1:2:3）；
- 口径：档位为回测节奏权重（总 60%），**实际执行按单票总敞口 ≤30% 等比缩放（每份≈5%仓位）**；
- 补仓（已持仓浮亏）：仅「恐慌深跌 + 供给收缩」V 型底指征，倒金字塔 3:2:1 递减、≤3 批、单批 ≤15%、总敞口 ≤30%；
- 停止：达单票敞口上限 / 状态转阴跌 / 供给扩张 → 立即禁加。

## 三、建仓操作清单（落地层）
1. 只在决策 buy 族触发时建仓（buy / oversold_buy 同口径，单品报告与批量扫描一致）；
2. 看决策条的「建议仓位 ≤X%」+ 批次节奏；首仓轻仓试探（≤目标仓 1/3）；
3. 确认后按方案 C 节奏分批加仓，批次金额按单票 ≤30% 缩放；
4. 组合约束：并发持仓 ≤80%（cap0.8）、单票总敞口 ≤30%、回撤 10% 视为信号质量劣化预警；
5. 补仓只认 V 型底指征，倒金字塔 3:2:1 递减，状态转阴跌立即禁补；
6. 每笔建仓/补仓记录执行 → 14/30 天复盘 → 用真实胜率/滑点/手续费反哺信号质量（期望须扣摩擦后仍为正）。

## 五、维护条款
- 本策略为**展示层/文档层**口径：不产生 buy/sell 信号，引擎参数未动；
- 方案 C 权重为 2026-08-04 回测产出，等比缩放在期望上线性，不改变其「分批优于一次性」的相对结论；后续随 J-2 三通道复验；
- 复验：A 独立恐慌事件≥3 / B 260 天数据（≈2027-04-25）/ C buy 胜率触发，复验后统一评估族级仓位与批次参数；
- 变更流程：算法/阈值改动先按 `project-principles.md`「数据先行」重跑回测，再改代码与本文档。
