# CORE-SAT-1 核心-卫星结构立项（2026-08-15，防踏空·收益增强第一性解）

> 版本：v1.0 | 日期：2026-08-15
> 性质：外审立项基线（目标重定义 + 架构 + 预注册 + 红线）。技术实现折入 `iteration-roadmap.md`（v72+）引用本文。
> 背景：全周期 3 年 benchmark 已实锤「引擎=风控器」（策略 +277.36%/−15.38% vs 池内等权 +539.43%/−54.33% vs 大盘 +12.45%/−58.21%）。**但风控器不是最终目标——用户目标是防踏空、收益增强。** 收益缺口已量化：−262pp vs 等权。
> 第一性判断：引擎是「纯崩盘反弹 alpha 机器」，把「长期增长 beta」整段丢掉了；而「预测牛市回调买点」已在信号日被三层证伪（价格/供给×价格/求购跟随均分不开陷阱）。因此防踏空的解不是再造牛市信号族，而是加一个「不预测、只跟随」的 beta 组件。

---

## 0. 目标重定义（防止方案跑偏）

| | 旧定调 | 新定调 |
|---|---|---|
| 系统是什么 | 风控器 | **以风控为护城河、以收益为目标的全周期投资者** |
| 成功标准 | maxDD 低 | **total 逼近等权的同时 maxDD 显著低于等权** |
| 主指标 | 期望 + Calmar/maxDD | **Calmar = total/maxDD**（单一度量：同时惩罚收益低与回撤高） |

---

## 1. 架构：核心-卫星（叠加，不是切换）

```
总资本 100%
├─ 核心 70%：现有引擎（panic/深值/供给收缩）——崩盘反弹 alpha，逻辑零改动
└─ 卫星 30%：牛市 beta 跟随——大盘 MA30>MA90 时等权持池内品，破位清仓
              + 品级 veto：Δspread > +8.9pp 的品跳过（今日挖出的陷阱指纹）
```

**为什么是叠加而不是切换**（关键，决定成败）：

| | 切换（两套引擎） | 叠加（核心-卫星） |
|---|---|---|
| 结构 | 熊市引擎 A / 牛市引擎 B，二选一 | 70/30 永远并存，各自管钱 |
| 依赖 | 需要「何时切换」的 regime 判断 | 不需要任何切换判断 |
| 判错代价 | 整仓押错 | 最多亏卫星 30%，核心不受污染 |

**历史教训**：TREND-GRID-1 / TREND-TIGHT-1 本质是「切换思路」，死在 regime 门分不开 2026-02~03 陷阱（与真趋势价格形态不可区分）。核心-卫星绕开这个坑——卫星错了死不了，对了就踏不上空。

---

## 2. 卫星规则（全部可回测、不依赖预测）

| 环节 | 规则 | 防什么 |
|---|---|---|
| 开仓 | 大盘指数 MA30 > MA90（多头排列） | 不判断「真牛/假牛」，纯跟随 |
| 持仓 | 池内品等权（96 品各 1/96 卫星仓位） | 无选品判断，吃全池 beta |
| 品级 veto | 建仓时该品 Δspread > +8.9pp → 跳过（陷阱指纹，A2-2 候选转实战） | 剔除极端走阔的派发品 |
| 清仓 | 大盘 MA30 < MA90 → 卫星整体清仓 | 牛市结束/假牛破位止损 |
| 仓位 | 卫星 ≤30%，核心 70% 不变 | 卫星错误损失封顶 |

## 3. 验证设计（3 年干净回放库，今天就能跑）

| 组 | 组成 | 预期 |
|---|---|---|
| 基线 A | 纯引擎 cap0.8 | +277.36% / −15.38% |
| 基线 B | 纯等权买入持有 | +539.43% / −54.33% |
| **实验 C** | 核心 70% + 卫星 30% + spread veto | 目标 ≥ +400% 且 maxDD ≤ −25% |

**预注册判定（三选一）**：

1. C 的 total ≥ +400% 且 maxDD ≤ −25% → **方向成立**，进细化设计（卫星调仓频率 / veto 阈值 / 70:30 比例网格）；
2. C 收益达标但 maxDD > −25% → 卫星仓位降 20% 重试；
3. C 收益 < +400% → 看拆解：卫星在 2024-09~2025-05 抓到牛市段没有？没抓到 = 卫星规则错（MA 周期/等权对象）；抓到了但被后续回撤吃光 = 清仓规则错。

**必须同时报**：实验 C 的年度 maxDD 拆解 + 卫星在四个小牛市窗口（2025-08~10 / 2025-11~12 / 2026-02~03 / 2026-05~06）的持仓与盈亏明细——这决定卫星是"真 beta"还是"碰运气"。

## 4. 红线

- 全部在 3 年回放库（replay_cycle_win.db）上模拟，零生产风险；
- **核心引擎逻辑零改动**——卫星是组合层叠加，不改任何信号族/阈值/闸门；
- 通过才谈落地，落地必 bump ENGINE_VERSION + 全链路 sync；
- 候选参数走 CS_ENGINE_* 开关；不 commit。

## 5. 执行顺序

```
① 三组对照模拟（A 纯引擎 / B 纯等权 / C 核心70+卫星30+veto）
② 报：三组 total/maxDD/Calmar + C 的年度 maxDD 拆解 + 卫星四小牛市窗口明细
③ 按预注册三选一判定
④ 方向成立 → 细化设计（比例/调仓/veto 网格）→ 再议落地
```

## 一句话收束

防踏空的第一性解 = **核心-卫星**：核心 70% 引擎继续抓崩盘反弹 alpha（已验证），卫星 30% 用 MA30>MA90 跟随抓牛市 beta（不预测、错了死不了），spread veto 剔除陷阱品。它不是两套引擎切换，是两条腿永远并存、70/30 分钱——**用「叠加 + 比例封顶」替代那个被证伪的「切换判断」**。验证线：实验 C ≥ +400% 且 maxDD ≤ −25% 即方向成立。
