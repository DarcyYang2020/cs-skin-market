# 迭代方案（Iteration Roadmap）

> **迭代闭环规则（2026-08-06 定稿）**：迭代执行 → 学习/试错 → 提炼新思路 → 映射为迭代项 →
> 更新本方案（版本 + 日期）→ 按优先级继续迭代。**若某轮实在没学到新东西，则不更新版本**（不为了更新而更新）。

> 变更纪律：每次更新先写版本变更说明，再改映射表/批次/状态。
