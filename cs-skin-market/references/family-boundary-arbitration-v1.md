# 全族边界仲裁表 v1（第二批产物，2026-08-16，登记版）

> 依据：探针 R（C）、S/S2（F）、T（D）+ 既有族（A/B/E/供给/风险态）。
> 性质：数据挖掘假设汇总，**非引擎落地**；每条边界均须样本外（B 通道/live pilot）确认后才可进引擎。
> 仲裁顺序 = 表内顺序（上优先）。

## 判定链（单品当日状态 → 族标签）

1. **G 风险态（派发/阴跌）**：sc30>0 且 价格 30d 下行 → 输出「派发风险提示」，不产生买点；若随后 3 日急拉（chg3≥8%）→ 进入 F 判别（见下）。
2. **F 反抽/真反转判别**（阴跌派发后急拉）：**承接(求购抗跌≥价格) × 拉阳量级(≥15%)** 双因子——双强=真反转候选（可转入买点评估）；双弱=反抽（仅风险提示）；缺求购数据不判。⚠ 当前窗口（2026-06~08）平台二波型正在失败（30d 30% vs 历史 49%），实盘先以风险提示口径观察。
3. **A 崩盘底/恐慌坑**：坑深（dd60≤-30 且情绪恐慌或 dd20≤-40 的止跌结构）→ panic 域（锁参）。与 C 的边界=**坑深 −30~−40 为过渡带**：带内看情绪（恐慌=A，无恐慌=C）。
4. **C 二波**：pct90≥70 + 回调（−5~−40 带内）→ 按 **回调深度 × 回调龄** 定质量：浅回调(−5~−10) 1-3d 快进；深回调(−20~−30) 6-10d + 承接为最强格；承接只在深回调必需。牛市（指180d>0）为默认环境，非牛降级。
5. **D 启动前**：慢涨(0<chg7≤5) + sc30≤-5 → 两个亚型：D1 震荡吸筹（高波，中高分位，14d/60d 均正）；D2 低位蓄势（低波×pct≤40，仅长持价值）。
6. **B 低位磨底/均值回归**：pct≤20~40 + 企稳 + 大盘深跌修复环境（deep_value/supply_accum 域，现有族）。
7. **E 退潮修复**：恐慌后次级反弹（sent 55-80 + mchg30≤-15 + 止跌）。
