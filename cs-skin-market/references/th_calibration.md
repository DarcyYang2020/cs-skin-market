## 1. 问题：TH 是熊市抄底血统的参数

系统架构已重构（统一大脑/信号族注册制），但核心阈值仍是旧抄底策略继承：
- `THRESHOLDS = {TH_STRONG: 55, TH_NEUTRAL: 35, TH_WEAK: 20}`
- 抄底场景要求 **TH 高**：deep_value 族 `th>=35 & market_th>=40`、融合决策深值 `p≤30 + TH>=55`、距买点参考线 `pct<=30 + TH>=55 + z<=-1.5`
- 而数据显示 **TH 低才是黄金坑**——TH 门槛把期望最高的恐慌深跌信号挡在门外、把期望最差的阴跌中继/接盘信号放进来。

## 3. 方案：TH 三区语义（牛熊不分家）

```
TH_FEAR   < 35   恐慌区    → 抄底腿黄金坑（TH 低=深跌恐慌，放行抄底）
TH_MID    35-54  摩擦区    → 降权：不做抄底入场，仅趋势腿辅助确认
TH_TREND >= 55   趋势区    → 趋势腿/短线动能（14d 高胜率小收益，不放深值抄底）
```

落地动作（由小到大）：

1. **deep_value 族门槛修正**（核心，`item_analysis.py`）
   - 现：`th>=35 & market_th>=40`（纳入 45-54 差档 + >=55 接盘档）
   - 改：`th>=45 剔除`；`th<35` 允许但需**止跌确认**（chg3d>0 / stopped）或大盘企稳（mth>=45）——与 panic_easing 共用止跌语义，避免阴跌中继
   - 预期（离线模拟剔除 45-54 深值 35 信号）：399→364，30d win 65.7→**67.9%**、avg +20.66→**+22.14**、net +18.66→+20.14；前后半段均不劣化（pre 60.5/+6.73、post 68.8/+24.2）
2. **融合决策深值档修正**（`market_th.py`，p<=30 场景）
   - 现：`TH>=55 + z<=0 → buy`（接盘档 52.2%/+10.68）
   - 改：th<35 恐慌深跌放行 / 35-54 观察 / >=55 仅趋势确认（不放深值 buy）
3. **展示层同步**（距买点参考线、batch_scan 文案）：`pct<=30 + TH>=55 + z<=-1.5` → 恐慌区 TH 可更低（TH<35 即黄金坑）
4. **大盘企稳（mth>=45）保持不动**：这是大盘企稳语义（P0-8，回测验证过），与单品 TH 三区语义是两条线
