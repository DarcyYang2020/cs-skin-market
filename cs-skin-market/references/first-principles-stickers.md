# 贴纸（印花）板块第一性原理分析 + 实现方案（2026-08-11）

> 范围：6 个 Major 赛事的**战队贴纸**（2021斯德哥尔摩 / 2022里约 / 2024哥本哈根 / 2024上海 / 2025奥斯汀 / 2025布达佩斯），
> 分组（竞争组/挑战者/传奇组）全做；命名规则：`印花 | 战队名（品质）| 年份赛事`（如 `印花 | G2 Esports（全息）| 2024年上海锦标赛`）。
> 本文回答：贴纸板块如何具体实现、现有引擎算法是否适合贴纸。

## 一、贴纸市场第一性原理

### 1.1 供给结构
- 贴纸**无磨损**（无 exterior），唯一供给 = **Major 赛事期间胶囊开箱产出 + 存量沉淀**；
- 胶囊按组别分发：**竞争组（Contenders）/ 挑战者（Challengers）/ 传奇组（Legends）**，每组约 8 支战队；
- 每支战队贴纸有 4 个品质：**普通（Paper）/ 闪亮（Glitter）/ 全息（Holo）/ 金色（Gold）**，稀有度溢价递增（金 > 全息 > 闪亮 > 普通）；本系统采集范围（2026-08-11 已确认）**仅全息（Holo）**：全息是价值/流动性最优梯队、波动低于金、样本充足；普通/闪亮/金色不做；
- 赛事结束后胶囊下架 → 供给冻结，贴纸进入**绝版沉淀**阶段（存量固定，价格由人气/事件驱动）。

### 1.2 需求与价格驱动
| 驱动 | 机制 | 可观测代理 |
|---|---|---|
| 赛事热度 | Major 前后需求脉冲（开赛前炒高 → 赛后回落） | 价格动量 + 在售量扩张 |
| 战队人气 | 粉丝/收藏需求，明星战队溢价稳定 | 长期价格分位 |
| 夺冠事件 | 冠军战队贴纸事件性暴涨 | 赛事日历 + 价格脉冲 |
| 绝版溢价 | 老 Major 存量固定，人气缓慢累积 | 长期趋势 + 在售量收缩 |
| 品质溢价 | 金/全息稀缺性 | 同战队跨品质价差 |

### 1.3 生命周期（与枪皮本质差异）
- 枪皮：开箱产出 → 存量随开箱增长（供给缓慢扩张），周期 = 洗盘/吸筹/拉升/出货；
- 贴纸：**脉冲式**——赛事前拉升、赛事中见顶、赛后崩盘、长期沉淀；**没有枪皮意义的"横盘吸筹"**；
- 贴纸的"低估区"出现在**赛后崩盘后**（价格回到发行价以下），与枪皮"深跌洗盘"在形态上相似、在成因上不同（枪皮洗盘=庄家吸筹，贴纸回落=热度退潮）。

## 二、现有引擎算法对贴纸的适配矩阵

| 引擎模块 | 适配 | 说明 |
|---|---|---|
| 位置分位 40%（`valuation.py`） | ✅ 适用 | 贴纸有价格 K 线；赛后低位 = 真实低估区，与已验证的「低估区反向信号」（2026-08-10 定论）同构 |
| 周期 25%（`item_analysis.py`，洗盘>吸筹>拉升>出货） | ⚠️ **语义错配** | 贴纸无横盘吸筹；赛事前"拉升"段 = 最危险追高段（周期定论"拉升/追高最差"反而适用）；赛事后"沉淀"段无对应周期标签 → 建议贴纸周期用**赛事生命周期**（发布/赛事/沉淀）替代或禁用周期因子，需 A2 验证 |
| 流动性 15%（在售深度+价格稳定） | ✅ 适用 | 在售量充足（样本 1100-1745）；价格稳定因子自动惩罚高波动贴纸，符合风险直觉 |
| 概率 20%（波动率 regime，高波中性偏弱） | ✅ 适用 | 贴纸年化波动 68-137% vs 枪皮 46%，高波 regime 天然抑制追高，是贴纸最重要的风险缓冲 |
| 供给×价格（`_dim_supply_price`） | ⚠️ 部分 | 「涨+供扩=派发嫌疑」对贴纸成立（赛事热度退潮抛售）；「供给收缩吸筹」对贴纸**不成立**（贴纸不主动收缩，仅在售量自然萎缩）→ 吸筹族对贴纸需禁用或重构 |
| 融合决策守卫链（大盘/存世量/半山腰/去重/飞刀） | ⚠️ 部分 | 大盘/去重/飞刀适用；「存世量」守卫需验证 csQAQ 贴纸存世量字段（statistic）；「半山腰」（位置>50% 禁买）对贴纸赛事前追高场景正确 |
| composite TH 偏移反向（`item_analysis.py:674`，M-5 落地） | ✅ 适用 | TH 高 = 拉升/追高段 → 反向降分，与贴纸赛事前炒高场景吻合 |
| 事件日历（EVENT_CALENDAR） | ✅ **强适用** | Major 是贴纸核心驱动；需确认日历覆盖 6 赛事 |
| 守卫2 微型 TH / 求购 / Z 门 | ✅ 适用 | 通用风控，无贴纸特异性问题 |
| 数据质量乘子（composite） | ✅ 适用 | 贴纸 K 线/in_sale_count 完整（csQAQ 支持） |

### 2.1 适配结论
- **引擎核心（位置/流动性/概率/风控/TH 反向）适配贴纸**：贴纸的"赛后低估反弹"与已验证的「低估区反向信号」「洗盘期最优（低估值优先）」同构，alpha 逻辑可迁移；
- **两处需要贴纸专用处理**：
  1. **周期因子**：现有洗盘/吸筹语义不适用贴纸 → 贴纸评分建议跳过周期因子（或映射为赛事生命周期），禁止直接套用；
  2. **供给吸筹族**：「供给收缩吸筹」对贴纸不成立 → 贴纸不触发吸筹族 buy，只走「低估区+大盘企稳」路径；
- **风险定性**：贴纸高波动（年化 68-137%）是**事件性风险**（可预测的赛事周期），非无规律投机 → 系统概率因子 + 守卫可消化；但**赛事前追高**是贴纸最大的亏损来源，必须由「半山腰守卫 + TH 反向 + 周期禁买」三层压制。

## 三、实现方案

### 3.1 采集范围与数量估算（2026-08-11 容器全量枚举已落地）
| 赛事 | 胶囊组别 | 全息战队贴纸数 |
|---|---|---|
| 2021斯德哥尔摩 | 竞争8/挑战8/传奇8 | 24 |
| 2022里约 | 竞争8/挑战8/传奇8 | 24 |
| 2024哥本哈根 | 竞争8/挑战8/传奇8 | 24 |
| 2024上海 | 竞争8/挑战8/传奇8 | 24 |
| 2025奥斯汀 | 竞争16/挑战8/传奇8 | 32 |
| 2025布达佩斯 | 竞争16/挑战8/传奇8 | 32 |
| **合计** | 18 个印花胶囊 | **160** |

- **品质范围（已确认 2026-08-11）**：**只做全息（Holo）**——6 赛事 × 24/32 战队 × 1 品质 = **160 品**（2025 起 Major 扩军 32 队）；全息是价值/流动性最优梯队，采集量可控、限流风险低。

### 3.2 数据层实现
1. **候选发现（2026-08-11 已验证打通）**：通过任一贴纸详情页「所属武器箱」入口触发 `GET /proxies/api/v1/info/good/container_detail?id={container_id}`，18 个胶囊（6 赛事 × 竞争/挑战/传奇）全量返回包含物（gid/名称/价格/稀有度）；无需登录，容器原始数据归档 `data/_capsule_containers/*.json`；
2. **过滤规则**：① 按名称 `（全息）` 过滤（**不可用 rln 稀有度字段**——csQAQ 映射随赛事漂移：2021=全息 / 2022=闪耀 / 2024=闪亮 / 2025奥斯汀=闪亮 / 2025布达佩斯=刺绣）；② 排除主办方贴纸（PGL / IEM / Perfect World / BLAST.tv / StarLadder，已剔除）；③ 战队胶囊不含选手签名（签名贴纸在独立签名胶囊）；
3. **入库**：`db.upsert_item` + K 线（`fetch_kline_90d`，悠悠锚校验串品防护沿用）；
4. **分组标注（竞争/挑战/传奇）**：来自胶囊归属（容器文件名已标注），写入 notes 备查（不做引擎输入）；
5. **品类识别**：`pipeline/item_categories.py` 已支持 `印花 |` → sticker ✓（M-6 阶段 1）。

### 3.3 发现层与追踪
- discover 池内白名单已含 `印花 |%` ✓（M-6 阶段 1）→ 贴纸入库后自动进发现空间；
- 发现榜按品类分桶展示（sticker 桶）✓；
- `discover_history` 已含 category 字段 → 贴纸 14/30d 追踪自动分桶（M-3 品类 alpha 检验基础）；
- **贴纸不进 buy 决策**（观察桶原则）：不触发吸筹族/供给收缩信号，仅"低估区+大盘企稳"路径候选，落地须过 A2（walk-forward + 聚类 + 置换）。

### 3.5 落地状态（2026-08-12 已执行）
- **入库**：160 品全息战队贴纸已入库（`source='sticker'`，notes=`赛事|分组|全息`，good_id=csQAQ gid），库内 items 203→361 品；去重核验：库内原有 MOUZ/G2 2024上海 2 品复用，无重复；
- **K 线**：158 新品的 90d K 线采集 147 品成功（86-92 根 bar/品），11 品两轮 EMPTY（限流窗口，2025 奥斯汀 6 + 布达佩斯 3 + 里约/哥本哈根各 1）留待每日任务自然补采；数据质量抽查通过（价格区间合理、无 ≤0/超高价、无长期零在售）；
- **观察桶守卫（代码落地）**：`pipeline/item_analysis.py:decide_fusion_signal` return 前新增 `sticker_observation` 守卫——`印花 |` 前缀品强制 buy→watch 降级（覆盖基础族/恐慌升级/后置族/超跌全部 buy 路径），验证：强 buy 场景贴纸=watch+sticker_observation、枪皮=buy 不变；panic_resonance 族原有印花排除保留（双保险）；
- **口径记录**：csQAQ `rln` 稀有度字段随赛事漂移（2021=全息/2022=闪耀/2024=闪亮/奥斯汀=闪亮/布达佩斯=刺绣），必须按名称「（全息）」过滤；主办方贴纸（PGL/IEM/Perfect World/BLAST.tv/StarLadder）已剔除。

### 3.4 待执行检验（A2 前置，样本积累后）
| 检验 | 数据/方法 | 判定阈值 |
|---|---|---|
| 贴纸赛后低估区反弹 | 6 赛事贴纸 90d 分位<25% 后 14d net2% vs 随机基线 | 三件套：信号数≥35 / 胜率>基线+5pp / 期望>0 |

## 四、风险清单
- P0（假信号）：无直接 buy 接线（观察桶原则）；潜在风险 = 赛事前追高误判为"低估"——由半山腰守卫 + TH 反向压制；
- P1（口径偏差）：周期因子/供给吸筹对贴纸语义错配（已在 3.4 立项检验，落地前禁用）；普通/闪亮贴纸价格低、2% 成本占比高（如 ¥15 贴纸成本 13%）→ 数据质量乘子需口径说明；
- P2（信息缺口）：已解决（container_detail 全量枚举，布达佩斯 32 队齐全）；剩余缺口 = 贴纸 K 线历史（2021斯德哥尔摩已上市 5 年，365d 窗口充足；2025 两赛事不足 365d 前勿入回测窗口）。

## 五、结论
- **贴纸板块可实现，引擎核心算法适配**（位置/流动性/概率/风控/TH 反向均适用）；
- **两处必须贴纸专用化**：周期因子禁用（或赛事生命周期映射）、供给吸筹族禁用；
- **落地路径**：采集（只做全息）→ 观察桶 → 追踪分桶积累 → A2 三件套验证 → 才可进 buy 决策；
- 与 `first-principles-market-fit.md` 衔接：贴纸补齐了「大赛事件驱动 + 高波动品类」的候选空间缺口（原 P2 信息缺口之一）。
