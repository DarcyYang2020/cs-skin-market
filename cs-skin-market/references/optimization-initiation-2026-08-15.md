## 0. 一句话总判断

今天真正的红利不是「补了断档」，而是发现了一个**可直连拉满 3 年历史的求购数据通道**——它把 BID-1 / LIQ-RATIO / SUPPLY-CONF-1 从「等样本」变成「能加速」，这才是下一阶段立项的主线。

## 一、第一梯队（立即，零引擎风险，纯数据层）

### BUY-1：求购数据直连化（最高优先）

- **目标**：用 csQAQ chart API 的 `key=buy_price / buy_num` + `period=1095`，一次性拉满 3 年求购价/量历史，替代/补充现有 Playwright 求购采集（贵、不稳、`bid_30d_chg` 曾不可信）。
- **为什么现在**：BID-1、LIQ-RATIO-1、SUPPLY-CONF-1 三个研究项全在等求购数据；直连通道今天已验证可用。
- **落地边界**：只进研究层（新表/补 `bid_history`），不碰 `items` / `price_history`，不接引擎。

#### BUY-1 数据质量闸门：10 品口径验证探针（先跑，通过才全量）

**scope**（选 10 个代表品，选样准则）：
1. **5 品** = 已有 `bid_history` 且 `bid_30d_chg` 曾标记「不可信/极端负值」的品 → 验证直连口径是否改善；
2. **3 品** = panic 族 / supply_accum 族高贡献品 → 验证求购与供给收缩的对齐关系；
3. **2 品** = 高价（≥1000）×1 + 低价 ×1 → 验证跨价格带求购量基数差异。

**验证口径**（直连 vs 现有 `bid_history`，按日对齐）：
- `buy_price` 日聚合值是否一致（日级偏差）；
- `buy_num` 日聚合值是否一致/分布接近；
- 重点：`bid_30d_chg` 在直连口径下是否**不再**「极端负值背离售价」。

**通过/不通过判据**：
- 通过 = `buy_price` 日级一致率 ≥95%（偏差 <5%）且 `bid_30d_chg` 不再极端背离 → 全量回填 + 挂每日增量，替代 Playwright；
- 有条件通过 = 价格一致但 `bid_30d_chg` 仍背离 → 说明是悠悠自身口径问题，直连不解决，维持现状、仅作快照；
- 不通过 = 价格不一致率 >5% → 直连口径与既有 bid_history 不同源，暂停，查明差异再定。

**判定输出**：一份 `data/_exp_buy1_gate.json`，含 10 品的直连 vs bid_history 对照表 + 三档结论。
