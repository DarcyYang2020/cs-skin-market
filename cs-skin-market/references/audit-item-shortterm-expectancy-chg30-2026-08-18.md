## 3. 独立复核

### 3.1 跨产物 n 一致性（循环性实证）

| 交叉核对 | 结果 |
|---|---|
| stage14 各期 n（P 4095 / S1 29738 / S2 15938 / S3 14192 / S4 13644）| = stage7 各期 n → **全样本建表确认** |
| stage15 最低校准桶 n=8314 且 actual_win=23.1 | = stage14 S3 深跌桶（n=8314 / win 23.1）→ **深跌 S3 的全部行都在 SPLIT 之后**（新 regime，train 内样本=0，与 BE 自述一致） |
| S3 浅跌 5878 − val 浅跌 2176 = 3702 | = stage11 样本内 S3 n=3702（+0.91% 良性）→ **pre-SPLIT S3 全部为浅跌** |

**结论**：深跌 S3 桶（−7.97%/23%，n=8314）的全部历史都发生在评估段（2025-08-10 后）。stage14 全样本建表 = **用「要预测的 regime 自身历史」回填该桶**——「方向错 76.7%→23%」的改善对该桶而言是 100% 样本内读数，**不存在任何深跌 S3 的样本外证据**（除非 B 通道该 regime 重现或 pilot）。

### 3.2 stage11 基线复核

S3 样本外（n=10490）：pred_med +0.88 vs actual_med −7.54，wrong_dir_pct **76.7** ✓（与用户转述一致）。P 样本外 wrong_dir 30.0%、S1 42.3%、S2 51.0%、S4 54.8%。基线（SPLIT 前训练）在 S3 上方向错误——诊断成立，但**这是对「修复」的动机诊断，不是修复本身有效性的证据**。

### 3.3 stage14 复核

数值与用户转述一致（S3 深跌 −7.97%/23.1%、浅跌 −0.14%/47.9%）。但：全样本建表（见 3.1），深跌 S3 桶 100% 样本内；产物 note 自认「样本内验证方向能力；坏 S3 是新 regime，样本外泛化靠领域知识外推+B 通道，不靠拟合」——**候选自认无样本外证据**。

### 3.4 stage15 复核 → 不可复核 + 内部矛盾 + 对照不公平

- **校准曲线内部矛盾**：桶标签（20-30% / 40-50% / 50-60% / 70-80%）与 `pred_win`（15 / 25 / 30 / 40）完全不匹配（如 70-80% 桶 pred_win=40，actual_win=70.0；20-30% 桶 pred_win=15）。该曲线无法解读，Brier 0.2718→0.2272 **无法从产物重建/复核**（产物无逐行预测明细）。
- **对照不公平**：基线 = SPLIT 前训练（val 上严格 OOS）；p1c = 全样本建表（val 上**样本内**——深跌 S3 桶直接由 val 行构成）。Brier 降 16.4% 至少部分/全部是「在评估样本上拟合」的机械收益，**不能归因于条件化的预测能力**。
- 校准曲线总 n = 8314+9412+14924+4004 = 36654 = val 段行数 → 曲线确在 val 段计算，但 p1c 模型已见该段数据。

### 3.5 P3 置换 → 产物未交付

④ 无文件名/文件。+2.96pp/+3.19pp/p=0.0000 **无法独立复算**（对照 stage7：上轮置换产物含 periods/n/D_real/D_perm_median/p 全字段，本轮缺失）。按红线「只认原始产物」→ ④ 证据缺失。

## 5. 与既有预注册 OOS 结论冲突

`current-state-expectancy-design.md` §6.5（决定性检验，train<2026-03 / test≥2026-03）：**period+mchg30 样本外 −1.81%（RMSE 改善）、spearman −0.067**；§6.6 钉死「②当下期望 = E[fwd14|时期,时点]，加任何单品/额外市场特征样本外变差」。本候选以**样本内 + 外推**证据拟推翻/绕开该既有 OOS 结论，未提供新 OOS 证据。按反过拟合纪律（用户明令）：**样本内不能推翻既有 OOS**。

## 6. 裁决：驳回

### 依据
1. **预注册判据缺失**：无 chg30 扩展立项卡/落地规格；机制替换未预注册即跑（违反变体实验纪律）——红线直接驳回项；
2. **核心证据为样本内 + 外推（候选自认）**：深跌 S3 桶 = regime 自身历史回填（跨产物 n 一致性实证），无任何样本外读数；「方向错 77%→23%」对该桶是循环论证；
3. **Brier 对照不公平 + 产物不可复核**：基线严格 OOS vs p1c 样本内；校准曲线内部矛盾（桶标签 vs pred_win），0.2718→0.2272 无法复核；
4. **P3 置换产物未交付**：④ 无法独立复算；
5. **与既有预注册 OOS 负面结论（mchg30 −1.81%）冲突**，无新 OOS 证据。

### 性质
非机制证伪（深跌 S3 显示 −7.97%/23% 作为「历史同态」描述是诚实且有用的展示校准），驳回点是：**判据缺失 + 证据不满足落地门槛（样本内不能落地）+ 产物不可复核**。
