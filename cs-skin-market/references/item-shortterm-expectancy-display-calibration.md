# 单品短期期望 · 展示校准收口方案（2026-08-18）

> 承接 decision-log BC~BI（单品短期期望「算得准」优化线收官）。
> 研究结论：可验证预测力上限 = 时期×时点（现状）；深跌 S3 的 −8%/23% 是「regime 自身历史均值，无样本外能力」。
> 本方案 = 审计复审路径⑤「展示校准豁免预测验证」口径收口——把深跌 S3 的「历史同态」作为**诚实展示**落地，不声称「预测」。

## 一、定位（关键区分）

| | 预测算法 | 展示校准 |
|---|---|---|
| 声称 | 「这个品未来会 −8%」 | 「深跌阴跌 regime 的历史同态中位数是 −8%」 |
| 样本外能力 | 需要 | 明确标注「无」 |
| 落地资格 | 需样本外验证 | 仅需「诚实描述 + 标注边界」 |

收口采用**展示校准**：不替换时期×时点的算法，只追加「深跌 S3 历史同态」的诚实标注。

## 二、落地内容（纯展示，不改算法）

当单品分析时，若当前市场 =「S3 弱市阴跌」且「chg30 ≤ −5%（深跌）」，短期期望卡片追加一行：

> ⚠️ 当前为深跌阴跌 regime（chg30 ≤ −5%）：历史同态 14d 中位数 −8.0%、翻正率 23%（n=8314）。该 regime 为历史未出现的新 regime，**无样本外能力，外推·低置信**，由 B 通道（~2027-04）/ live pilot 承担。

- 数据来源：`data/_exp_stage14_p1c_extrapolation.json` 的 S3 深跌桶（−7.97%/23.1%/n=8314）。
- 不改 `compute_shortterm_expectancy`（查表逻辑不动），不改决策、不 bump ENGINE_VERSION。

## 三、落地边界（红线）

1. 纯展示：只在 `webapp/analysis_service.py` 追加一行标注 + `analysis.html` 渲染。
2. 不把 chg30 条件化写入 `compute_shortterm_expectancy`（它是「预测」，无样本外能力，不落地）。
3. 不 bump ENGINE_VERSION；冒烟测试不得回退（当前 131 passed）。

## 四、与审计的关系

对应 ③审计#3 复审路径⑤「预注册『展示校准豁免预测验证』口径经 PM 立项」。本方案即为该口径：深跌 S3 的 −8%/23% 作为「历史同态描述」展示，明确标注「无样本外能力」，不声称「预测」，故豁免预测验证，由 PM 立项 + 研发落地。
