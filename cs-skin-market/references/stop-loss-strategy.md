## 一、第一性原理：CS 市场里止损到底在买什么

### 1.1 止损不是「看错就跑」，而是「尾部截断」
- 平均收益由买入信号质量决定（buy 370：14d 不止损 72.4%/+17.9%）；止损决定的是下限——不被 -60% 套死。
- 回测对照：buy 信号状态止损 71.9%/+17.8%，与不止损几乎相同；但触发子样本（浮亏≥-15%）深套率 20.7% → 7.0%。止损是保险，不是收益来源。

### 1.2 浮亏 ≠ 判断错误
- 判断错误的信号是**结构性**的：单品供给扩张（派发结构）、大盘阴跌中继（下跌未完成）。
- 判断正确的浮亏是**暂时**的：恐慌深跌（V 型底前）、中性震荡（洗盘）、大盘上涨段回踩。
- 结论：止损必须按「状态」分桶；固定 -25% / 90 日新低一刀切，会把 V 型底筹码和上涨段洗盘筹码洗掉。

### 1.3 CS 市场特性对止损的约束
| 特性 | 对止损的影响 |
|---|---|
| T+7 锁仓 | 恐慌当日无法卖出，止损只能日频评估，无法日内逃顶 |
| 流动性分层 | 冷门品止损即砸盘（价格冲击），执行要挂单限时、先出流动性好的部分 |
| 强周期 + 事件驱动 | 恐慌深跌多为事件利空出尽后的 V 型底（2026-05 例），砍在底部=接盘别人恐慌 |
| 散户情绪超涨超跌 | -15% 浮亏大概率是洗盘而非错误，结构性恶化才是错误 |

### 1.4 补仓的本质：只有 V 型底指纹有正期望
- 恐慌深跌 + 单品供给收缩（量价配合的 V 型底指纹）→ 回测 win87% / +43.7%，值得补。
- 阴跌中继补仓 = 接飞刀；供给扩张补仓 = 接派发盘；贪婪区补仓 = 追高。全部禁补。

## 二、回测方法（可复现）

- 样本：池内 90 日 K 线（含大盘指数）；buy 信号 370 次 + 任意日买入采样 2619 次（每品每 20 交易日一采样）。
- 模拟：持仓模拟，浮亏≥-15% 触发评估 → 按状态矩阵决策。
- 成本：止损执行价 = 触发日价 ×(1-2% 滑点)；net 额外扣 2% 成本。
- 指标：14d/30d/60d/90d 胜率 + 平均收益 + 深套率（<-30%）。
- 对照组：不止损 / 状态矩阵止损 / 全损 / 减半。

### 2.1 核心结论（三句话）
1. buy 信号无需常规止损——触发评估仅 8~12%，常规止损只吃掉洗盘筹码。
2. 止损只在浮亏触发子样本里有价值——深套率砍掉 2/3（20.7%→7.0%）。
3. 状态分桶是胜负手——恐慌/中性/上涨段不止损正确，供给扩张/阴跌中继必须止损（减半）。

## 三、五状态止损矩阵（F-3.7 定稿）

| 状态 | 判定条件 | 动作 | 回测证据（60d/90d） |
|---|---|---|---|
| 供给扩张 | 单品 in_sale 30日 +5% | 全止损（结构性恶化） | 深套 41%→1%，派发结构无反弹预期 |
| 恐慌深跌 | 大盘 mchg30 ≤-15% | 不止损 → 转补仓评估 | 60d +1.4% / 90d +7.6%，深套≤12% |
| 阴跌中继 | 大盘 -15%<mchg30≤-5% | 减半止损 | 深套 17.6%→3.4%（全损 -21.1 / 扛单 -11.6 折中） |
| 大盘上涨段 | 大盘 mchg30 >5% | 不止损 | 90d 扛 +29% vs 止损 -21.6% |
| 中性 | 大盘 -5%<mchg30≤5% | 不止损 | 90d +51%（深套 19%，靠仓位控制） |

- 优先级：供给扩张 > 大盘状态（单品结构性恶化优先）。
- 触发线：浮亏达成本线 -15% 触发评估（非直接止损）。
- 执行参考价 = 触发日现价（成交按市场价记录，滑点口径 = 成交价÷现价−1）；stop_price = 90日关键支撑，仅作挂单参考（避免市价砸穿），不作为成交参考价。
- 阴跌中继减半 = 一半按止损价锁定、一半继续持有；执行先出流动性好的部分。

## 四、补仓规则（V 型底指纹）

- 触发：恐慌深跌（mchg30≤-15%）+ 单品供给收缩（in_sale 30日走低/价格企稳）。
- 禁补：阴跌中继 / 供给扩张 / 贪婪区（sent≤30）。
- 节奏：倒金字塔递减 3:2:1，单批≤15%仓位，总敞口≤30%。
- 停止：≤3 批 / 达单票敞口上限 / 状态转阴跌立即禁补。
- 回测：V 型底指纹 win87% / +43.7%（早期预研口径，样本扩大后复验）。

## 六、维护条款

- 本策略为**持仓管理展示层建议**：不产生 buy/sell 信号，不触碰 PARAM_FREEZE（冻结参数未动）。
- 回测数据唯一事实源：`data/stop_loss_backtest.json`（generated=2026-08-09）。
- 近似口径：sent 情绪无历史数据，以 mchg30 近似大盘状态；数据积累后可替换为真实情绪。
- 复验：随 J-2 三通道（A 独立恐慌事件≥3 / B 260 天新数据≈2027-04-25 / C buy 胜率触发），复验后统一评估矩阵阈值与补仓参数；展示层探索不阻塞冻结纪律。
- 变更流程：算法/阈值改动先按 `project-principles.md`「算法改动必须数据先行」重跑回测，再改代码与本文档。
- 待办/未决：补仓后的离场阈值未定（暂沿用持有周期 15-45 天）；恐慌深跌 V 型底回测为早期预研口径，样本扩大后复验。
