> 最后更新: 2026-07-16 | 版本: v3.2

## 一、数据输入

| 输入 | 来源 | 说明 |
|---|---|---|
| 90日K线 (prices) | csQAQ Playwright 采集 | 每日收盘价数组，最旧→最新，约90个数据点 |
| 日成交量 (volumes) | csQAQ K线数据 | 与 prices 等长，可能不准确 |
| 存世量 (vol_total) | csQAQ 详情页 | 单品总存世量 |
| 订单簿 (order_book) | csQAQ 详情页 | spread_pct 等 |
| 大盘指数变化 | csQAQ API | index_change_7d 用于辅助判断 |
| 板块相关性 | 大盘K线 + 单品K线 | 滚动相关系数 |
| 物品元数据 | 数据库 items 表 | rarity, source, discontinued_years |
| 品类参数 | config.CATEGORY_PARAMS | mad_scale(波动率修正), liq_floor(流动性底线) |

## 二、十大分析模块

### 1. 估值定位 `_analyze_position`

**功能**: 判断当前价格在90日历史中的位置

**算法**:
- 百分位 = 低于当前价的历史价格数 / 总价格数 × 100
- Z-score = (当前价 - 均值) / 标准差
- 分档: 0-30% 低估 / 30-70% 合理 / 70-100% 高估 / 90%+ 极度泡沫

**输出**:
- 当前价、90日百分位、Z-score
- 估值档位 + 标签
- 90日最高/最低/均值/中位数
- 数据点数量

**用途**: 回答"现在贵不贵"


### 2. 周期判定 `_analyze_cycle`

**功能**: 识别价格所处的四阶段周期

**算法 (v3.2)**:
- **吸筹期**: 百分位≤30% + MA7>MA30，低位均线上穿
- **拉升期**: MA7>MA30 + 百分位 30-65%，合理区间上行
- **出货期**: MA7>MA30×1.05 + 百分位≥65%（乖离5%才判定），或 MA7<MA30 + 百分位≥70% + 乖离>3%
- **洗盘/换手期** (新增): MA7<MA30 + 百分位 50-70% + 乖离≤3% → 小幅回调判为健康换手，非出货
- **洗盘期**: MA7<MA30 + 百分位≤50%

**新增 (v3.2)**:
- 成交量确认：拉升期要求近5日均量 > 20日均量，否则降级为"无量拉升·警惕"
- MA90过滤：价格在MA90下方时，禁止判定为拉升期，最多判为"修复反弹"
- 周期持续天数统计

**输出**:
- 阶段标签 + 置信度
- 阶段描述 + 操作策略
- 下一阶段触发条件
- 持续天数

**用途**: 回答"现在处于行情的哪个阶段"


### 3. 流动性评估 `score_liquidity`

**功能**: 评估出货难度和交易活跃度

**算法** (三维 0-100):
- 日成交量 (0-40): 按成交量档位给分
- 存世深度 (0-30): 总存世量档位给分
- 波动稳定 (0-30): 近30日日收益率绝对值均值

**v3.2 新增**:
- 按品类 liq_floor 动态调整权重
- 流动性趋势分：近30日流动性环比变化
- 五档梯度约束融合决策

**输出**:
- 0-100 总分
- 五档标签: 极佳(85+) / 良好(70+) / 一般(50+) / 较差(30+) / 极差(<30)
- 风险警告: <70分提示出货困难

**用途**: 回答"能不能顺利卖出"


### 4. 涨跌概率预测 `analyze_probability`

**功能**: 基于均值回归理论预测未来涨跌概率

**算法 (v3.2)**:
- 核心假设: Z-score 偏离越大，回归力量越强
- 扩张特征池：纳入趋势健康分、庄盘概率、周期阶段、大盘环境
- 趋势衰减: TH<30 时上涨概率向50%收敛（弱势趋势不预测反弹）
- 波动率修正: 高波环境下上涨概率被压缩
- 输出概率置信标签（高/中/低）
- 输出 3/7/30 日三个时间框架

**输出**:
- 上涨概率 / 震荡概率 / 下跌概率 (三日)
- 预期收益 (%)
- 波动率区间标签 (stable/normal/volatile/high_volatile)
- 概率置信度
- 关键支撑位 / 压力位 (叠加均线+历史百分位密集区)

**用途**: 回答"接下来涨的概率有多大"


### 5. 投资价值评级 `compute_value_score`

**功能**: 综合评分 1-10，输出 S/A/B/C 评级

**算法**:
- 基础分 = 百分位分 + Z-score分 + 流动性分 + 周期分
- 被趋势健康度修正 (+-2.0)
- 被融合决策修正 (+-1.5 ~ +-2.0)
- 被庄盘检测压制（极端庄盘上限2.0）
- 被事件风险折价（炼金材料×0.85 / 纪念品×0.8 等）
- 被供给分析修正

**输出**:
- 1-10 评分
- S(8+) / A(6.5+) / B(4.5+) / C(<4.5) 评级
- 操作建议 + 推荐理由

**用途**: 回答"综合来看值不值得投资"


### 6. 庄盘识别 `analyze_whale`

**功能**: 检测人为操纵/资金抱团迹象

**算法** (四因子加权):
- 量价背离 (0-40分): 价涨量缩 / 价跌量增
- 波动异常 (0-25分): 波动率突变
- 持仓锁紧 (0-20分): 供给持续收缩+价稳/涨
- 价格异动 (0-15分): 异常缺口(使用MAD修正阈值)

**v3.2 新增**:
- 订单簿挂单壁检测（整数关口大额挂单）
- 庄盘类型标记：低位吸筹锁仓 / 无量拉升诱多 / 高位放量出货

**输出**:
- 0-100 概率
- 四因子明细分数
- 庄盘类型 + 交易规则

**用途**: 回答"这个行情是真实的还是人为操纵"


### 7. 趋势健康度 `compute_trend_health` (trend_health.py)

**功能**: 评估趋势的可持续性和健康程度

**算法** (六维度 0-100, v3.2):
- **趋势持续性 (24%)**: 连续7日在MA7上方且乖离温和扩大→满分；反复穿插均线→折中；连续7日低于MA7→0分
- **趋势陡度 (24%)**: 近7日价格线性回归斜率，归一映射；加速上涨→高分；斜率收敛拐头→低分
- **均线结构 (19%)**: MA7/MA30/MA90三重检测；三重多头→满分；上穿MA30但价低于MA90→减半
- **量价配合 (18%)**: 涨放量跌缩量→满分；涨缩量(无量拉升)→扣分；跌放量(恐慌)→扣分
- **支撑压力验证 (10%)**: 回踩MA30不破→加分；触及90日高点回落→减分；突破前高放量→加分
- **异常缺口风险 (15%)**: 基于MAD修正标准差，单日涨跌>±1.8MAD判定异常；梯度扣分

**修正层 (乘性改为最大单一修正+上限)**:
- 出货期修正: direction-based 分级 (上×0.8 / 平×0.65 / 下×0.5)
- 庄盘修正: whale_prob>60% → ×0.7
- 方向封顶: 下跌方向上限45（深度超跌MAD Z<-2.2企稳→上限60）
- 取最大单一负面修正，避免连续乘性压制

**输出**:
- 0-100 健康度总分 (原始/修正后)
- 五维度子分数
- 趋势方向 + 置信度
- 扣分来源列表
- 异常缺口类型

**用途**: 回答"这个趋势能持续吗"


### 8. 融合决策 `compute_fusion_decision` (trend_health.py)

**功能**: 百分位 + 修正趋势健康度 → 单一操作决策

**算法 (三区矩阵, v3.2)**:

**低估区 (0-30%)**:
| TH≥60 | TH 40-59 | TH<40 |
|---|---|---|
| 分批建仓 | 筑底观察 | 下跌中继·观望 |

**合理区 (30-70%)**:
| TH≥70 | TH 50-69 | TH<50 |
|---|---|---|
| 短线持有 | 震荡观望 | 回调·关注 |

**高估区 (70-100%) — v3.2 方向感知**:
| TH范围 | 方向向上 | 方向走平 | 方向向下 |
|---|---|---|---|
| TH≥70 | 抱团行情·分批止盈 | (同左) | (同左) |
| TH 40-69 | **强势整理·持有观察** | 高位横盘·减仓 | 回调风险·减仓观察 |
| TH<40 | 高位震荡·减仓 | 高位震荡·减仓 | **趋势反转·清仓** |

**极端保护**: 百分位>95% + Z-score>2.5 → 强制"极端泡沫·建议清仓"

**新高估区量价感知**: TH≥70且方向向上→检查量价配合：健康→"强势趋势·持有"；背离→"抱团风险·分批止盈"

额外过滤: 流动性<30 → 建仓降级为观望

**输出**:
- 操作: buy / hold / reduce / sell / watch / avoid
- 操作标签 + 操作说明
- 百分位区间标签
- 原始TH / 修正后TH

**用途**: 回答"现在应该做什么"


### 9. 估值宫格 `compute_valuation_grid` (valuation.py)

**功能**: 3行(百分位) × 4列(趋势强度) 可视化定位 + 仓位建议

**行** (百分位):
- 低估 0-30% / 合理 30-70% / 高估 70-100% (90%+ 极度泡沫)

**列** (修正后趋势健康分):
- 强上涨 TH≥75 / 弱反弹 TH 60-74 / 横盘 TH 40-59 / 下跌/虚假 TH<40
- 抱团概率>60% → 强制降级为"虚假上涨"

**12格每格输出**:
- 定位标签 + 操作 + 颜色
- 仓位建议 (轻/中/重仓 + 分批节奏)
- 止盈止损参考

**用途**: 回答"买多少、什么时候卖"


### 10. 辅助因子 AuxFactors

**功能**: 补充性量化指标

**指标**:
- 90日均价
- 7日均量
- 换手率 (日成交/存世量 %)
- MA30偏离率
- 资金流斜率

**用途**: 辅助判断，不参与核心决策


### 11. 信号冲突检测 (v3.2 新增)

**功能**: 检测多模块之间的信号矛盾

**检测对**:
- 估值低估 + 庄盘高概率 → "可能庄家压价吸筹，也可能是流动性差导致的伪低估"
- 趋势健康高分 + 周期出货 → "短期趋势强劲但处于出货阶段，可能是诱多"
- 估值低估 + 周期出货 → "低价但大盘出货期，可能是价值陷阱"

**输出**: 冲突记录列表 + 决策确定性评分


### 12. 供给/事件风险 (v3.2)

**功能**: 评估供给端变化和事件风险

**供给分析**:
- 在售数量变化率
- 供给趋势 (expanding/contracting/stable)
- 吸筹检测 / 派发检测

**事件风险折价**:
- 炼金材料 ×0.85
- 纪念品 ×0.8
- 收藏品(受2026.5炼金解禁影响) ×0.75

## 三、品类参数 (CATEGORY_PARAMS)

v3.2，按 csQAQ type_name 区分波动率特征：

| 品类 | mad_scale | liq_floor | 说明 |
|---|---|---|---|
| 手套 | 0.8 | 5 | 低波动，阈值收紧 |
| 匕首 | 0.8 | 3 | 低波动 |
| 步枪 | 1.0 | 10 | 基准 |
| 手枪 | 1.1 | 8 | 基准偏上 |
| 微型冲锋枪 | 1.2 | 6 | 中等波动 |
| 霰弹枪 | 1.3 | 4 | 中等波动 |
| 机枪 | 1.2 | 3 | 中等波动 |
| 印花 | 2.0 | 2 | 高波动，阈值放宽 |
| 胶囊 | 2.2 | 1 | 高波动 |
| 收藏品 | 2.5 | 1 | 极高波动 |
| 探员 | 1.3 | 3 | 中等波动 |
| 音乐盒 | 1.5 | 2 | 中等波动 |

mad_scale 用于异常缺口检测的自适应阈值（阈值 = 1.8 × MAD × mad_scale）

## 五、v3.2 更新日志

### 相比 v3.1 的变更

1. **周期检测**: 小幅回调(MA7<MA30 但乖离≤3%)不再误判为出货期，改为"洗盘/换手期"
2. **周期检测**: 新增成交量确认和MA90中长期过滤
3. **出货期修正**: 从一刀切×0.5 改为方向分级 (上×0.8 / 平×0.65 / 下×0.5)
4. **趋势健康度**: 六维度全部中文化（多头排列/量价配合/情绪泡沫 等）
5. **趋势健康度修正层**: 乘性改为最大单一修正，避免连续压制
6. **品类参数**: 新增 CATEGORY_PARAMS，mad_scale 自适应不同品类的波动率特征
7. **趋势衰减**: TH<30 时上涨概率向50%收敛，弱势趋势不预测反弹
8. **波动率区间**: ProbPrediction 新增 volatility_regime 字段
9. **融合决策**: 高估区新增方向感知，方向向上→"强势整理·持有观察"，避免小回调被误判清仓
10. **融合决策**: 新增极端估值保护（百分位>95%+Z>2.5强制清仓）
11. **估值宫格**: 3×4宫格替换旧3×3，趋势强度四档区分
12. **信号冲突检测**: 新增跨模块矛盾检测
13. **流动性**: 五档梯度约束融合决策
14. **庄盘识别**: 新增订单簿挂单壁检测 + 庄盘类型标记
