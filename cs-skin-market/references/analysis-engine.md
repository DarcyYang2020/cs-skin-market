> 最后更新: 2026-07-16 | 版本: v3.1

## 一、数据输入

| 输入 | 来源 | 说明 |
|---|---|---|
| 90日K线 (prices) | csQAQ Playwright 采集 | 每日收盘价数组，最早->最新，约90个数据点 |
| 日成交量 (volumes) | csQAQ K线数据 | 与 prices 等长，可能不准确 |
| 存世量 (vol_total) | csQAQ 详情页 | 单品总存世量 |
| 订单簿 (order_book) | csQAQ 详情页 | spread_pct 等 |
| 大盘指数变化 | csQAQ API | index_change_7d 用于辅助判断 |
| 板块相关性 | 大盘K线 + 单品K线 | 滚动相关系数 |
| 物品元数据 | 数据库 items 表 | rarity, source, discontinued_years |
| 品类参数 | config.CATEGORY_PARAMS | mad_scale(波动率修正), liq_floor(流动性底线) |

## 二、十大分析模块

### 1. 估值定位 analyze_position

**功能**: 判断当前价格在90日历史中的位置

**算法**:
- 百分位 = 低于当前价的历史价格数 / 总价格数 x 100
- Z-score = (当前价 - 均值) / 标准差
- 分档: 0-20% 低估 / 20-70% 合理 / 70-90% 高估 / 90%+ 泡沫

**输出**:
- 当前价、90日百分位、Z-score
- 估值档位 + 标签
- 90日最高/最低/均值/中位数
- 数据点数量

**用途**: 回答"现在贵不贵"

---

### 2. 周期判定 analyze_cycle

**功能**: 识别价格所处的四阶段周期

**算法 (v3.1 更新)**:
- **吸筹期**: 百分位<=30% + MA7>MA30，低位+均线上穿
- **拉升期**: MA7>MA30 + 百分位 30-65%，合理区间上行
- **出货期**: MA7>MA30*1.05 + 百分位>65%（乖离>5%才判定），或 MA7<MA30 + 百分位>70% + 乖离>3%
- **洗盘/换手期** (新): MA7<MA30 + 百分位 50-70% + 乖离<=3% → 小幅回调判为健康换手，非出货
- **洗盘期**: MA7<MA30 + 百分位<=50%

**输出**:
- 阶段标签 + 置信度
- 阶段描述 + 操作策略
- 下一阶段触发条件

**用途**: 回答"现在处于行情的哪个阶段"

---

### 3. 流动性评估 analyze_liquidity

**功能**: 评估出货难度和交易活跃度

**算法** (三维 0-100):
- 日成交量 (0-40): 按成交量档位给分
- 存世深度 (0-30): 总存世量档位给分
- 波动稳定 (0-30): 近30日日内收益率绝对值均值

**输出**:
- 0-100 总分
- 五档标签: 极佳(85+) / 良好(70+) / 一般(50+) / 较差(30+) / 极差(<30)
- 风险警告: <70分提示出货困难

**用途**: 回答"能不能顺利卖出"

---

### 4. 涨跌概率预测 analyze_probability

**功能**: 基于均值回归理论预测未来涨跌概率

**算法**:
- 核心假设: Z-score 偏离越大，回归力量越强
- 趋势衰减: TH<30 时上涨概率向50%收敛（弱势趋势不预测反弹）
- 波动率修正: 高波环境下上涨概率被压缩
- 输出 3/7/30 日三个时间框架

**输出**:
- 上涨概率 / 震荡概率 / 下跌概率 (三日)
- 预期收益 (%)
- 波动率区间标签 (stable/normal/volatile/high_volatile)
- 关键支撑位 / 压力位

**用途**: 回答"接下来涨的概率有多大"

---

### 5. 投资价值评级 analyze_value_score

**功能**: 综合评分 1-10，输出 S/A/B/C 评级

**算法**:
- 基础分 = 百分位分 + Z-score分 + 流动性分 + 周期分
- 被趋势健康度修正 (+-2.0)
- 被融合决策修正 (+-1.5 ~ +-2.0)
- 被庄盘检测压制（极端庄盘上限2.0）
- 被事件风险折价（炼金材料x0.85 / 纪念品x0.8 等）

**输出**:
- 1-10 评分
- S(8+) / A(6.5+) / B(4.5+) / C(<4.5) 评级
- 操作建议 + 推荐理由

**用途**: 回答"综合来看值不值得投资"

---

### 6. 庄盘识别 detect_whale

**功能**: 检测人为操纵/资金抱团迹象

**算法** (四因子加权):
- 量价背离 (0-40分): 价涨量缩 / 价跌量增
- 波动异常 (0-25分): 波动率突变
- 持仓锁紧 (0-20分): 供给收缩 + 价格异常平稳
- 相关异常 (0-15分): 与大盘/板块相关性异常

**输出**:
- 0-100% 庄盘概率
- 四档: 自然散户(<=12%) / 弱庄抱团(<=30%) / 强庄控盘(<=55%) / 极端庄盘(>55%)
- 异常标记列表
- 交易规则

**用途**: 回答"这个价格是市场定价还是庄家定价"

---

### 7. 趋势健康度 v3 trend_health.py

**功能**: 衡量价格趋势的质量和可持续性

**算法** (五维度标准化 0-100):

| 维度 | 权重 | 核心逻辑 | 输出 |
|---|---|---|---|
| 趋势持续性 | 24% | N=7日收盘价 vs MA7，连续站稳满分，反复穿插折中 | 连续上穿/下穿天数 + 乖离变化 |
| 趋势陡度 | 24% | 7日线性回归斜率归一化 + 二阶导数检测衰竭/加速 | 加速上涨 / 上涨衰竭 / 恐慌下跌 / 触底企稳 / 拐头向上/向下 / 匀速稳定 |
| 均线结构 | 19% | MA7/MA30/MA90 三重排列，新增MA90中长期锚定 | 多头排列 / 空头排列 / 修复反弹 / 走弱转跌 / 中性无序 |
| 量价配合 | 18% | 涨放量跌缩量满分，无量拉升或恐慌出逃扣分 | 量价配合 / 量价背离 / 高位派发 / 量能中性 |
| 异常缺口 | 15% | MAD修正标准差（按品类 mad_scale 自适应），>1.8MAD扣分 | 情绪泡沫 / 恐慌抛压 / 混合异常 / 无异常 |

**修正层 (v3.1 新增方向感知)**:

| 修正来源 | 触发条件 | 修正幅度 |
|---|---|---|
| 方向封顶 | direction=down | 上限45; direction=flat 上限65 |
| 出货期修正 | cycle=distribution | 方向向上x0.8 / 走平x0.65 / 向下x0.5 |
| 高位洗盘 | price/MA90>1.20 + consolidation | x0.7 |
| 低位洗盘 | consolidation 非高位 | x0.9 |
| 庄盘抱团 | whale_prob>60% | x0.7 |
| 持仓锁紧 | position_lock>15 | x0.6 |

**输出**:
- 原始分 + 修正分
- 五维度明细分数
- 趋势方向 + 置信度
- 扣分来源列表
- 异常缺口类型

**用途**: 回答"这个趋势能持续吗"

---

### 8. 融合决策 compute_fusion_decision

**功能**: 百分位 + 修正趋势健康度 -> 单一操作决策

**算法 (三区六档矩阵, v3.1 高分位区新增方向感知)**:

**低估区 (0-30%)**:
| TH>=60 | TH 40-59 | TH<40 |
|---|---|---|
| 分批建仓 | 筑底观察 | 下跌中继·观望 |

**合理区 (30-70%)**:
| TH>=70 | TH 50-69 | TH<50 |
|---|---|---|
| 短线持有 | 震荡观望 | 回调·关注 |

**高估区 (70-100%) — v3.1 方向感知**:
| TH范围 | 方向向上 | 方向走平 | 方向向下 |
|---|---|---|---|
| TH>=70 | 抱团行情·分批止盈 | (同左) | (同左) |
| TH 40-69 | **强势整理·持有观察** | 高位横盘·减仓 | 回调风险·减仓观望 |
| TH<40 | 高位震荡·减仓 | 高位震荡·减仓 | **趋势反转·清仓** |

额外过滤: 流动性<30 -> 建仓降级为观望

**输出**:
- 操作: buy / hold / reduce / sell / watch / avoid
- 操作标签 + 操作说明
- 百分位区间标签
- 原始TH / 修正后TH

**用途**: 回答"现在应该做什么"

---

### 9. 估值宫格 3x4 valuation.py

**功能**: 3行(百分位) x 4列(趋势强度) 可视化定位 + 仓位建议

**行** (百分位):
- 低估 0-30% / 合理 30-70% / 高估 70-100% (90%+ 极度泡沫)

**列** (修正后趋势健康分):
- 强上涨 TH>=75 / 弱反弹 TH 60-74 / 横盘 TH 40-59 / 下跌/虚假 TH<40
- 抱团概率>60% -> 强制降级为"虚假上涨"

**12格每格输出**:
- 定位标签 + 操作 + 颜色
- 仓位建议 (轻/中/重仓 + 分批节奏)
- 止盈止损参考

**用途**: 回答"买多少、什么时候卖"

---

### 10. 辅助因子 AuxFactors

**功能**: 补充性量化指标

**指标**:
- 90日均价
- 7日均量
- 换手率 (日成交/存世量 %)
- MA30偏离率
- 资金流斜率

**用途**: 辅助判断，不参与核心决策

## 三、品类参数 (CATEGORY_PARAMS)

v3.1 新增，按 csQAQ type_name 区分波动率特征：

| 品类 | mad_scale | liq_floor | 说明 |
|---|---|---|---|
| 手套/匕首 | 0.8 | 3-5 | 低波动，阈值收紧 |
| 步枪/手枪 | 1.0-1.1 | 8-10 | 基准 |
| 微冲/霰弹/机枪 | 1.2-1.3 | 3-6 | 中等波动 |
| 印花/胶囊 | 2.0-2.2 | 1-2 | 高波动，阈值放宽 |
| 收藏品 | 2.5 | 1 | 极高波动 |
| 探员/音乐盒 | 1.3-1.5 | 2-3 | 中等波动 |

mad_scale 用于异常缺口检测的自适应阈值（阈值 = 1.8 * MAD * mad_scale）

## 五、v3.1 更新日志

### 相比 v3 的变更

1. **周期检测**: 小幅回调(MA7<MA30 但乖离<=3%)不再误判为出货期，改为"洗盘/换手期"
2. **出货期修正**: 从一刀切 x0.5 改为方向分级 (上x0.8 / 平x0.65 / 下x0.5)
3. **融合决策高分位区**: 新增方向感知，方向向上->"强势整理·持有观察"，避免小回调被误判清仓
4. **趋势健康度子指标**: 全部中文化 (多头排列/量价配合/情绪泡沫 等)
5. **品类参数**: 新增 CATEGORY_PARAMS，mad_scale 自适应不同品类的波动率特征
6. **趋势衰减**: TH<30 时上涨概率向50%收敛，弱势趋势不预测反弹
7. **波动率区间**: ProbPrediction 新增 volatility_regime 字段
