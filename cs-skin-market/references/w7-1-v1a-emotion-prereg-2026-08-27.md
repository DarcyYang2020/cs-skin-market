## 0. 目标（W7-1 v1a 卡原文）

评估 v0 升级版（补 bid/spread 盘口因子）能否带来**相对核心因子集（及相对 v0）的新增信息量**——R1 组9 已证 bid/spread 单因子弱/无效，v1a 检验**合成非线性交互**是否翻盘。

## 1. v1a 情绪分定义（组件 + 合成规则）

**组件（全部 R1 已评估或 W7-1 已核验，数据事实在先）**：

| 组件 | 定义 | R1/EF 证据 | 角色 |
|---|---|---|---|
| 恐慌分 | approx_sentiment（价格行为代理：大跌=恐惧高分） | R1：IC14=+0.142 稳定 / **候选·无增量** | 主组件（v0 复用） |
| 供给变化 | sc30（在售量 30 日变化） | R1：+0.029 / 候选（条件IC） | 调节（v0 复用） |
| 价格动量 | chg7（7 日动量） | R1：−0.130 / 不稳定（反转） | 反向调节（v0 复用） |
| **bid** | buy_price_max（悠悠最高买价，bid_history） | R1 组9：IC14=−0.011 / 弱/无效；EF：fit 774 天全量可回测 | **增量主候选** |
| **spread** | price − buy_price（点差派生，price×bid） | R1 组9：IC14=−0.097 / 不稳定；EF：86.9% 覆盖可回测 | 增量候选（流动性代理） |

**v1a 合成规则（简单、可复现、跑前定死）**：
- `emo_v1a = clip(emo_v0 + w3·bid_norm + w4·spread_norm, 0, 100)`
- 其中 `emo_v0 = clip(恐慌分 + w1·sc30_norm − w2·chg7_norm, 0, 100)`（R5 冻结定义，w1=w2=0.5）；
- **权重固定禁优化**：`w1=w2=w3=w4=0.5`（v0 同款规则；权重变化=新预注册）；
- 归一化：bid_norm/spread_norm 用 fit 段逐日截面 rank（0-100，R5 同规则）；
- 方向：bid 正向（买价高=买盘强=情绪高）+w3；spread 正向 +w4（点差大=流动性差=情绪弱——**spread 合成方向按理论语义取正号，合成后整体方向由数据判定，不做方向预筛选**）；
  - 注：R1 组9 spread IC 为负（−0.097）是**单因子截面 IC**（spread 大→fwd 低），与合成内符号解耦——合成符号是**预注册定死**的规则（不照镜子），增量 IC 判定的是合成后残差，不依赖单因子方向。

## 2. 与现有因子正交性（增量 IC，防冗余）——硬判据

- **判据 A（对齐 R5 同口径，可比）**：对核心因子集（pct/z/chg30/sc30/vol30/mchg30，R1/R5 同款）截面回归取残差 → 残差 vs fwd14 的**增量 IC ≥0.02 且滚动稳定（同号月≥80%）→ 候选成立**；否则无增量/证伪登记；
- **判据 B（v1a 特有：相对 v0 的净增量）**：对核心因子集 **+ emo_v0** 联合截面回归取残差 → 增量 IC ≥0.02——回答"**bid/spread 是否在 v0 之上还有新信息**"（v0 已证无增量，v1a 若只有 v0 的贡献不算翻盘）；
- **verdict 规则**：**判据 A 且判据 B 均过 → v1a 候选**；任一不过 → 无增量/证伪登记（正负都登记）；
- 若 v1a 无增量：登记"无增量（与 R1/R5 合并口径）"，不推进——诚实预期：单组件弱/无效 + v0 无增量，合成大概率仍无增量，但非线性交互值得按流程验证一次。

## 3. 使用方式边界（跑前定死）

1. **仅守卫/加分**：v1a 若候选，仅作引擎守卫链附加维度（如恐慌高分对深值/恐慌族加分、情绪极端过滤），**不进打分主干、不改族触发、不改 position_limit**；
2. **进引擎 = 守卫变更**：走完整管线（R4 清单步骤 7-10：组合候选守卫→回放→四关→③审计→PM 立卡→研发落地→挂监测），本判据 §4 预注册四关方案；
3. **v1b/v1c**：turnover（需 ≥3 月积累）/ steamdt（W7-2 积累 3-6 月）——数据到位后**重新预注册**（本判据不含）。

## 4. 族开回放与四关方案（仅当增量 IC 候选成立触发）

> 若 §2 verdict=候选 → 按此方案族开回放 + 完整四关（对齐 R3 预注册口径，north_star 指标）。

- **族开回放**：v1a 作为候选守卫族注入引擎（单族模式：非目标守卫恒 False + 守卫开关 patch），全池 3 年回放（replay_cycle_win.db，405 items 口径）→ 对照当前引擎无注入基线；
- **完整四关**（逐关过线，跑前定死）：
  1. **A2 发射复算**：fit 段 p_avg 显著（≤0.05）**且** val 段不显著即证伪（val p 趋近 1.0 = 无样本外证据 = 证伪）；
  2. **组合级（b1）**：守卫开启组合的**风险调整后收益 ≥ 基线（全引擎）同口径**——主比 Calmar/最大回撤（north_star 风险预算），次比总收益；劣化 ≥10pp 即不过；
  3. **前后半段**：切点 2025-08-10（oos_zone 同点），前半段 win14 ≥60% **且** 后半段（val）win14 ≥60% 且期望为正——val 段不显著即证伪；
  4. **置换检验**：随机移除同规模信号（n_iter=500 seed=42），val 段收益差 p ≤0.05 才算"非随机"；p 趋近 1 = 证伪；
- **组合增益线**：若守卫变更通过四关 → 等权/A2 期望加权组合 vs 单引擎基线：north_star 口径增益 ≥0 且回撤不劣化 → 守卫变更成立；否则维持现状；
- **差异化证据**：守卫触发信号与现有族信号重叠（Jaccard）+ 收益相关矩阵 + 时期覆盖三表（R3 同款）。
