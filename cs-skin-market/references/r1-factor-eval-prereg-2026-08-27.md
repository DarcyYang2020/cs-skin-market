## 2. 评估口径（跑前定死）

### 2.1 截面 IC（主口径）
- 每日 t：当日截面所有品，`Spearman(因子值_i, fwd_i)`；
- 日 IC 序列 → 报告：均值、标准差、t 值、IC>0 占比；
- 截面 IC 天然控制时期/市场涨跌混杂（08-26 已拍板）。

### 2.2 前向窗口
- **net14 为主、net30 为辅**（矩阵 fwd14/fwd30 直接读）。

### 2.3 时期分段
- **五时期**：P恐慌深跌 / S1牛市上行 / S2牛市回调 / S3 / S4——沿用生产 period_route 口径（config PERIOD_ROUTE，评估脚本复用同一函数，保证口径一致）；
- **fit/val 双段**：fit < 2025-08-10；val ≥ 2025-08-10 = **oos_zone，探索不触碰**（D6）；
- 每时期报告 IC 均值/符号/样本量。

### 2.4 覆盖率
- fit 段因子可算比例（非空/总行）；
- 分档：**≥80% = 主评资格；30–80% = 低覆盖·结果参考；<30% = 待数据**（组 9 spread/bid 预期落此档）。

### 2.5 分层测试（5 档）
- 按因子 5 等分（quintile），报告各档 fwd14 均值/胜率；
- 单调性：价值/动量/波动类**必须单调或 U 型可解释**；供给类（组 5/6）**不硬判单调**，改看条件 IC（sc30 收缩 vs 扩张条件下的价格行为 IC）；
- 翻转（fit 单调、val 反向）→ 标「不稳定」。

### 2.6 滚动稳定性
- 按月滚动截面 IC：同号月份占比（**≥80% = 稳定 / 50–80% = 不稳 / <50% = 无效**）+ 显著月份数。

### 2.7 单时期依赖检查（08-21 单月簇教训）
- 五时期中仅一个时期显著 → 标「单时期依赖」，不视为稳健信号（2024-02 爆发月 / 2025-08 牛市月同类陷阱的显式防线）。

## 3. 增量 IC / 相关性去重

- **核心因子集**：已进引擎的因子（以 factor_registry status=生产 为准；R2 落定前先以引擎六维：pct/z/动量/供给/波动/市场）；
- 候选因子对核心因子做**截面回归取残差**，残差与 fwd14 的 IC = **增量 IC**；
- 因子间 IC 相关（截面相关逐日均值）**>0.8 = 冗余**，标「冗余于 XXX」，不单独给结论；
- **增量 IC ≥0.02 且稳定 = 提供新信息（候选）；<0.02 = 无增量（登记）**。

## 4. 组合方法（本轮仅声明，不做组合回测）

- 等权 / IC 加权（权重 ∝ IC 或 IC/σ）；
- **禁优化器**：均值-方差 / 风险平价优化 / ML 权重学习一律不做（§3.2 纪律 + §2.2 挖掘纪律）。

## 5. 硬判据（跑前定死，正负都登记）

1. **oos_zone 守院**：评估脚本默认仅 fit 段；val 段仅在预注册声明的验证动作中触碰，探索触碰 = **本轮无效 + 台账告警**；
2. 单因子 **|IC14 均值| < 0.05** → 标「弱/无效」；**≥0.05 且滚动稳定（同号月 ≥80%）** → 标「候选」；时期符号翻转或单时期依赖 → 标「不稳定/单时期」；
3. **证伪登记**：无效/不稳定/翻转因子登记证伪进 registry（防重复挖，sentiment 预期落此）；
4. **组9 spread/bid 升主评**（DE 修订，2026-08-27）：bid_history 经 PM 只读核验为 3 年全量（1,144 天，2023-06-27~2026-08-14），删除「待数据」降级，改与主评 IC 同口径；评估须 `date < '2025-08-10'` 过滤排除 val（oos_zone 守院）；**其余因子**覆盖率 <30% 仍标「待数据」不判好坏；
5. 本轮输出 = 10 组评估卡（JSON），**结论只到筛查层**，不产生引擎改动、不立落地卡。
