# 「当下进场期望」机制设计（2026-08-18，预注册，研究版）

> 目标：补上 audit 第 ③ 节缺失的「② 当下条件期望」——给定当前市场 + 单品状态，算出"现在进场"的历史条件期望。
> 反过拟合纪律：本文方法/特征/阈值/校验全部**先注册后跑**，样本内结果只产出候选，落地须样本外或 live pilot。

## 一、语义定义（单一事实源）

- **当下条件期望** = 对"与当前状态**特征相似**的所有历史 (item, day)"，其 fwd14/fwd30 的分布（均值 / 胜率 / n / CI）。
- 与「③ 历史分布（引擎信号）」的本质区别：**条件在特征上，不在引擎发射历史上**。引擎 189 条信号会碎成 n<5，但全宇宙（180 品 × 3 年 ≈ 16 万 item-day）条件匹配可得 n 数百至数千。

## 二、数据基础：宇宙面板（universe panel）

- 对 180 品 × 3 年每个 (item, day)（warmup 后）记录：市场特征 + 单品特征 + fwd14/fwd30。
- **存原始值，不存分桶**——分桶是分析层选择，改了不用重跑 31 分钟面板。
- 产物：`data/_exp_universe_panel.json`（columnar，~16 万行 × 15 列）。

### 特征集（预注册，小且可解释）

市场（5）：`period`（五时期）/ `period_days`（进入第 N 天，整数）/ `mchg30`（大盘30日）/ `mchg180` / `mth`（大盘TH）/ `sent`（情绪）。
单品（6）：`pct`（90日分位）/ `z` / `th`（单品TH）/ `cycle`（四阶段）/ `supply30`（在售30日变化）/ `chg7`。
结果（2）：`fwd14` / `fwd30`。

## 三、估计方法：贪心顺序条件 + 收缩（预注册）

1. **桶化**（预注册分档）：
   - `period`：5 桶（P/S1/S2/S3/S4）。
   - `period_days`：1-7 / 8-14 / 15-30 / 31+（对齐 P14 口径，但只是一维）。
   - `pct`：≤15 / 15-30 / 30-70 / >70。
   - `z`：≤-2 / -2~-0.5 / -0.5~0.5 / >0.5。
   - `th`：<35 / 35-54 / ≥55（三区语义，**仅作条件变量，不作买点定义**，让数据自己说话）。
   - `cycle`：吸筹/拉升/出货/洗盘。
   - `mchg30`：≤-15 / -15~-3 / -3~3 / >3。
   - `sent`：≤40 贪婪 / 40-70 中性 / >70 恐惧。
2. **贪心顺序**（固定顺序，逐维加入，只用 n≥阈值 且 前后半段方向一致的维）：
   `period` → `pct` → `period_days` → `th` → `z` → `cycle` → `mchg30` → `sent`。
3. **收缩**：`Ê_cell = λ·mean_cell + (1-λ)·mean_period`，`λ = n/(n+k)`，**k=20 预注册**。n<5 直接回退到 `mean_period`（并标"样本不足"）。
4. **CI**：均值 ± 1.96×std/√n（粗 CI）+ Wilson 95% 胜率区间。

## 四、校验（walk-forward，预注册判据）

- 时间切分：train = 2023-11~2026-02，test = 2026-03~2026-08。
- 判据：test 段上，条件期望的**排序能力**（Spearman(预测条件均值, 实际 fwd14)）> 全局均值基线；且 train/test 的"桶内均值方向"一致性（无 sign flip 且 |Δ| 不过大）。
- 证伪即重做，不重试调参；正负结果均登记 decision-log。

## 五、展示口径（落地后）

- 对查询状态 q（当前市场 + 单品）：输出 `E[fwd14]` / 胜率 / n / CI，附"历史分布，非本次胜率"标签；n<5 → "样本不足"。
- 例：S3弱市阴跌 + 低估区建仓 100% 时，展示 = "历史同态（S3·pct≤30·th=X·进入第44天）：14d 均值 ±X% / 胜率 X%（n=…）"——而非"此时期 78%"。

## 六、探针结果（2026-08-18，已跑，诚实登记）

面板 `_exp_universe_panel.json`（87074 行原始，过滤 chg180 退化日 8100 后 **78974** 清洁 item-day）。估计 `_exp_current_state_expectancy.json`。

### 6.1 时期级 fwd14（全宇宙，最强信号）

| 时期 | n | mean | win |
|---|---|---|---|
| P恐慌深跌 | 4095 | **+18.09%** | 70.4% |
| S1牛市上行 | 29738 | +5.81% | 56.8% |
| S2牛市回调 | 15938 | +5.39% | 55.4% |
| **S3弱市阴跌** | 14192 | **−3.95%** | **33.3%** |
| S4弱市反弹 | 13644 | +3.81% | 46.5% |

→ 强排序 P ≫ S1/S2 > S4 ≫ S3，与引擎路由（P抄底/S1持多/S2回调买/S3空仓/S4反抽陷阱）**逐条吻合**。

### 6.2 S3 时点衰减（全宇宙，非仅引擎信号）

| 进入 S3 第 N 天 | mean fwd14 | win |
|---|---|---|
| 1-2 | +1.7 / +0.5% | 46.6 / 45.1% |
| 3-7 | −1.5 ~ −4.2% | 32.9~39.5% |
| 8-14 | −5.3 ~ −7.5% | 23~32% |
| **15-27** | **−6.4 ~ −10.5%** | **10~31%** |

→ 单调衰减：S3 越晚进越糟。**当前实盘 S3 已 44 天，而全历史 S3 最长仅 32 天（回放终点 2026-08-05）——第 44 天是历史未见状态，样本不足，最近邻（15-32 天）= −7~−10%。**

### 6.3 S3 内估值分层（低估区无边际）

pct≤15 / 15-30 / 30-70 / >70 → fwd14 全部 −3~−5%（win 30~37%）。**低估区（pct≤30）在 S3 = −3.9%，与高估区无异——阴跌市里"便宜"不构成优势，接飞刀无效。**

### 6.4 「黄金坑」研究结论不外推（关键证伪）

「th<35 黄金坑 win 80.8%/+36」是**引擎信号选择偏差**的产物。全宇宙口径下，S3+低估区+th<35 的 fwd14 = **−3.5%**（win 37.7%，n=469）——**"黄金坑"在全宇宙是负期望态**。这印证 audit E 类：研究结论被当买点定义，但全宇宙条件期望证伪了它。

### 6.5 walk-forward + 特征层级增量校验（决定性结论）

增量校验（`validate_feature_levels.py`，train<2026-03 / test≥2026-03，k=20，RMSE 改善 vs 全局均值）：

| 条件方案 | RMSE 改善 | Spearman |
|---|---|---|
| **period** | +2.63% | 0.278 |
| **period+period_days** | **+3.52%** | 0.207 |
| period+period_days+pct | +3.08% | 0.122 |
| period+period_days+pct+th | +2.60% | 0.089 |
| period+period_days+pct+th+z | +2.12% | 0.077 |
| period+pct+th | +2.77% | 0.102 |
| period+cycle | +2.63% | 0.278 |
| period+mchg30 | **−1.81%** | −0.067 |
| period+sent | −0.01% | 0.108 |

→ **决定性结论：②当下期望 = f(时期, 时点) 最优。往里面加任何单品特征（pct/th/z）或额外市场特征（mchg30/sent/cycle）在样本外都反而变差（过拟合/冗余）。**

深层原因：五时期 taxonomy 本身就是从 chg180×chg30 数据挖掘出来的「历史周期」，已经编码了"现在市场情况"——再加原始 mchg30/sent 是冗余，加单品 pct/th 是噪声。这印证用户直觉的正解：**"历史周期挖掘 + 现在市场情况" = 五时期 + 时点，而非更多维特征堆叠。**

### 6.6 最终口径（钉死）

- **②当下期望 = E[fwd14 | 时期, 时点]**（k=20 收缩，n<5 回退标"样本不足"），带"历史分布，非本次胜率"标签。
- 单品特征（pct/th/z）**不进** ②（样本外无边际）；它们仍属于 ① 引擎触发条件（proximity 应镜像的）。
- 例：S3+低估区建仓100% → 展示"进入 S3 第 44 天（历史最长 32 天，样本不足）；S3 时期 fwd14 均值 −4.0%/胜率 33%；近邻（第 15-27 天）−7~−10%"——而非"低估区 100% 就绪"。

## 七、落地边界

- 本机制是**展示层研究产物**，不进引擎触发；引擎买点定义仍以 `SIGNAL_FAMILIES` + `compute_fusion_decision` 为单一事实源。
- E 类修复（proximity 与 trigger 同源）与本机制并行，二者共同构成"② 当下期望 + ① 事实源"的完整闭环。
